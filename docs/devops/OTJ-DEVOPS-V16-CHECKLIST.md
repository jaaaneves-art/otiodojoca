# OTJ-DEVOPS-V16 — Checklist Operacional

**Código:** OTJ-DEVOPS-V16  
**Projeto:** O Tio do Joca (OTJ)  
**Área:** DevOps  
**Versão:** 1.0  
**Estado:** Em desenvolvimento

---

# Objetivo

Disponibilizar uma checklist operacional para apoiar a preparação, validação e manutenção da infraestrutura DevOps do projeto OTJ, reduzindo o risco de falhas e promovendo procedimentos consistentes.

---

# Checklist Pré-Deploy

## Código

- [ ] Código revisto.
- [ ] Pull Request aprovada.
- [ ] Testes concluídos.
- [ ] Documentação atualizada.

## Pipeline

- [ ] Build concluída.
- [ ] Testes automáticos aprovados.
- [ ] Artefactos gerados.
- [ ] Pipeline sem erros.

## Configuração

- [ ] Variáveis de ambiente verificadas.
- [ ] Segredos atualizados.
- [ ] Configuração validada.
- [ ] Dependências atualizadas.

---

# Checklist de Produção

- [ ] Backups recentes disponíveis.
- [ ] Certificados SSL válidos.
- [ ] Firewall ativa.
- [ ] Monitorização operacional.
- [ ] Sistema de logs ativo.
- [ ] Alertas configurados.

---

# Checklist Pós-Deploy

- [ ] Aplicação acessível.
- [ ] APIs operacionais.
- [ ] Base de dados funcional.
- [ ] Autenticação validada.
- [ ] Métricas dentro dos valores esperados.
- [ ] Logs sem erros críticos.

---

# Checklist de Segurança

- [ ] Atualizações aplicadas.
- [ ] Contas desnecessárias removidas.
- [ ] Permissões revistas.
- [ ] Segredos protegidos.
- [ ] Auditorias registadas.

---

# Checklist de Backups

- [ ] Backup diário concluído.
- [ ] Backup semanal disponível.
- [ ] Teste de recuperação realizado.
- [ ] Integridade validada.

---

# Checklist de Monitorização

- [ ] CPU monitorizada.
- [ ] Memória monitorizada.
- [ ] Disco monitorizado.
- [ ] Serviços monitorizados.
- [ ] Alertas testados.

---

# Revisão Periódica

Esta checklist deverá ser revista regularmente para acompanhar a evolução tecnológica do projeto e incorporar novos procedimentos DevOps.

---

# Conclusão

A utilização sistemática desta checklist contribui para uma operação mais segura, previsível e eficiente da plataforma O Tio do Joca.
