# Objetivo

Esta pasta contém toda a documentação técnica relacionada com a estratégia de DevOps do projeto **O Tio do Joca**.

O objetivo é definir as normas, processos, ferramentas e procedimentos necessários para garantir que o sistema pode ser desenvolvido, testado, distribuído, monitorizado e mantido de forma segura, consistente e escalável.

---

# Âmbito

A documentação DevOps cobre todo o ciclo de vida operacional da plataforma, incluindo:

- Desenvolvimento
- Integração contínua
- Entrega contínua
- Infraestrutura
- Containers
- Deploy
- Segurança
- Monitorização
- Backups
- Recuperação

# Objetivos da estratégia DevOps

A implementação DevOps pretende assegurar:

- Automatização máxima
- Redução de erros humanos
- Rapidez nas entregas
- Elevada disponibilidade
- Segurança da infraestrutura
- Facilidade de manutenção
- Escalabilidade horizontal e vertical
- Recuperação rápida perante falhas

---

# Tecnologias previstas

O projeto poderá utilizar, entre outras, as seguintes tecnologias:

- Git
- GitHub
- GitHub Actions
- Docker
- Docker Compose
- Nginx
- Let's Encrypt
- Node.js
- Next.js
- Supabase
- PostgreSQL
- Linux Ubuntu Server
- PM2 (quando aplicável)

A lista poderá evoluir conforme o crescimento da plataforma.

# Princípios

Toda a infraestrutura deverá seguir os princípios:

- Infraestrutura documentada
- Configuração reproduzível
- Deploy automatizado
- Segurança por defeito
- Menor privilégio
- Backups frequentes
- Observabilidade completa
- Recuperação testada
