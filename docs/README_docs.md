# Documentação do Projeto OTJ

Bem-vindo à documentação oficial do projeto **O Tio do Joca (OTJ)**.

Esta pasta reúne toda a documentação técnica, funcional e de gestão do
projeto.

## Estrutura

``` text
docs/
├── README.md
├── architecture/
├── backend/
├── frontend/
├── database/
├── api/
├── security/
├── devops/
├── qa/
├── project-management/
└── sessions/
```

## Descrição das pastas

  Pasta                Descrição
  -------------------- ----------------------------------------
  architecture         Arquitetura da plataforma e ADR
  backend              Documentação do backend
  frontend             Documentação do frontend
  database             Modelo e documentação da base de dados
  api                  APIs, endpoints e contratos
  security             Segurança, autenticação e autorização
  devops               CI/CD, infraestrutura e deployment
  qa                   Testes e garantia de qualidade
  project-management   Planeamento, ADR, roadmap e gestão
  sessions             Histórico das sessões de trabalho

## Convenções

-   Toda a documentação é escrita em Markdown.
-   Cada área possui um `README.md`.
-   As decisões arquiteturais são registadas em ADR.
-   As sessões de trabalho são registadas na pasta `sessions`.

## Objetivo

Manter a documentação organizada, consistente e atualizada ao longo da
evolução do projeto.
