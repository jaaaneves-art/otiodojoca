# Product Documentation

## OTJ --- O Tio do Joca

Bem-vindo à documentação de Produto da plataforma **O Tio do Joca
(OTJ)**.

Esta coleção descreve a visão do produto, as funcionalidades, os perfis
de utilizador, os principais casos de utilização, o roadmap e o
glossário de termos.

## Objetivos

-   Definir a visão do produto.
-   Documentar as funcionalidades.
-   Identificar os perfis de utilizador.
-   Descrever os principais fluxos de utilização.
-   Planear a evolução da plataforma.
-   Uniformizar a terminologia utilizada em toda a documentação.
