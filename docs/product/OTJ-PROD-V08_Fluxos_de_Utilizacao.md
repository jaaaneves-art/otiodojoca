# OTJ-PROD-V08 — Fluxos de Utilização

## 1. Objetivo do documento

Descrever os principais fluxos de utilização da plataforma **O Tio do Joca (OTJ)**, identificando as interações entre os utilizadores e os módulos funcionais.

---

# 2. Fluxo de Registo

1. Aceder à plataforma.
2. Criar conta.
3. Confirmar o endereço de correio eletrónico.
4. Completar o perfil.
5. Iniciar sessão.

---

# 3. Fluxo de Publicação de Conteúdos

1. Autenticar.
2. Criar conteúdo.
3. Validar informação.
4. Publicar.
5. Atualizar quando necessário.

---

# 4. Fluxo do Mercado da Terra

1. Registar produtor.
2. Criar produtos.
3. Publicar.
4. Atualizar disponibilidade.

---

# 5. Fluxo de Eventos

1. Criar evento.
2. Publicar.
3. Divulgar.
4. Atualizar informação.

---

# 6. Fluxo Administrativo

1. Monitorizar plataforma.
2. Gerir utilizadores.
3. Moderar conteúdos.
4. Consultar auditorias.

---

# 7. Relação com outros documentos

Relaciona-se com:
- Personas
- Casos de Utilização
- Requisitos Funcionais
- Módulos Funcionais
