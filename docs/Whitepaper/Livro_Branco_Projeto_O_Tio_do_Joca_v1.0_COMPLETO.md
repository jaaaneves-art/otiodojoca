# Livro Branco do Projeto O Tio do Joca

## Versão Oficial 1.0

**Data de aprovação:** 13 de julho de 2026

------------------------------------------------------------------------

# 1. Missão

O Tio do Joca pretende preservar, organizar e divulgar o património
cultural português, tornando-o acessível às gerações atuais e futuras
através de meios digitais e impressos.

O projeto pretende ser uma referência nacional na divulgação da
história, tradições, cultura popular, património, natureza, agricultura
e identidade portuguesa.

------------------------------------------------------------------------

# 2. Visão

Construir o maior arquivo digital independente dedicado à cultura
tradicional portuguesa, combinando rigor histórico, tecnologia moderna e
participação da comunidade.

------------------------------------------------------------------------

# 3. Valores

-   Rigor histórico
-   Independência editorial
-   Respeito pelas fontes
-   Neutralidade política
-   Neutralidade religiosa
-   Preservação do património
-   Partilha do conhecimento
-   Transparência
-   Acesso livre sempre que possível

------------------------------------------------------------------------

# 4. Objetivos

O projeto deverá reunir informação sobre:

-   História de Portugal
-   História Local
-   Património
-   Monumentos
-   Castelos
-   Igrejas
-   Museus
-   Aldeias
-   Vilas
-   Cidades
-   Tradições
-   Festas
-   Romarias
-   Gastronomia
-   Agricultura
-   Jardinagem
-   Animais
-   Calendário agrícola
-   Calendário lunar
-   Provérbios
-   Ditados
-   Lendas
-   Mitos
-   Personagens portuguesas
-   Biodiversidade
-   Caminhos
-   Turismo
-   Genealogia
-   Arquivos históricos
-   Fotografia antiga
-   Cartografia
-   Meteorologia popular

------------------------------------------------------------------------

# 5. Plataforma

O projeto será composto por módulos independentes:

-   Portal Principal
-   Comunidade (Fórum, comentários, perfis)
-   Feira
-   Biblioteca
-   Almanaque
-   Enciclopédia

------------------------------------------------------------------------

# 6. Tecnologia

Tecnologias atualmente previstas:

-   Next.js
-   React
-   TypeScript
-   Tailwind CSS
-   Supabase
-   PostgreSQL

A arquitetura deverá permitir evolução e migração futura sem perda de
informação.

------------------------------------------------------------------------

# 7. Princípios de Desenvolvimento

Todas as funcionalidades deverão privilegiar:

-   Simplicidade
-   Robustez
-   Segurança
-   Escalabilidade
-   Facilidade de utilização
-   Compatibilidade móvel
-   Compatibilidade desktop

------------------------------------------------------------------------

# 8. Segurança

O desenvolvimento deverá respeitar:

-   RGPD
-   Proteção de dados pessoais
-   Backups automáticos
-   Controlo de permissões
-   Auditoria das ações principais

------------------------------------------------------------------------

# 9. Conteúdo

Todo o conteúdo deverá ser:

-   Verificável
-   Datado
-   Referenciado sempre que possível
-   Escrito em português europeu
-   Revisto antes da publicação

------------------------------------------------------------------------

# 10. Inteligência Artificial

A IA será utilizada como ferramenta de apoio à:

-   organização
-   pesquisa
-   indexação
-   revisão
-   geração de rascunhos
-   programação

Nunca substitui a decisão editorial.

------------------------------------------------------------------------

# 11. Comunidade

A comunidade deverá promover:

-   colaboração
-   entreajuda
-   respeito
-   educação
-   preservação da memória

Não serão tolerados:

-   insultos
-   discurso de ódio
-   spam
-   fraude
-   desinformação deliberada

------------------------------------------------------------------------

# 12. Sustentabilidade

O projeto procurará sustentabilidade através de:

-   publicidade não intrusiva
-   donativos
-   parcerias
-   venda de livros
-   serviços premium opcionais

Sem comprometer a independência editorial.

------------------------------------------------------------------------

# 13. Organização

Documentação oficial:

-   Livro Branco
-   Livro Técnico
-   Manual Editorial
-   Manual da Comunidade
-   Histórico de Alterações

------------------------------------------------------------------------

# 14. Evolução

Este documento define os princípios permanentes do projeto.

As funcionalidades poderão evoluir sem alterar os seus valores
fundamentais.

------------------------------------------------------------------------

# 15. Compromisso

O Projeto **O Tio do Joca** compromete-se a preservar, valorizar e
transmitir a cultura portuguesa utilizando as melhores ferramentas
tecnológicas disponíveis, mantendo sempre o respeito pela verdade
histórica, pela comunidade e pelo património nacional.
