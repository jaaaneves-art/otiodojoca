# OTJ-DEV-001 --- Guia de Desenvolvimento

# Capítulo 2 --- Organização do Código

## 2.1 Finalidade

Este capítulo define os princípios para a organização do código-fonte do
Projeto O Tio do Joca, assegurando uma estrutura clara, modular e
facilmente evolutiva.

## 2.2 Objetivos

A organização do código deverá:

-   facilitar a manutenção;
-   promover reutilização;
-   reduzir acoplamento;
-   simplificar navegação no repositório;
-   apoiar o crescimento do projeto.

## 2.3 Estrutura do Repositório

O repositório deverá separar claramente:

-   frontend;
-   backend;
-   base de dados;
-   APIs;
-   documentação;
-   scripts;
-   testes;
-   recursos partilhados.

## 2.4 Organização dos Módulos

Cada módulo deverá possuir responsabilidades bem definidas, evitando
dependências desnecessárias e favorecendo componentes reutilizáveis.

## 2.5 Convenções

A estrutura de diretórios, nomenclatura de ficheiros e organização dos
componentes deverão seguir convenções consistentes e documentadas.

## 2.6 Evolução

A organização do código poderá evoluir ao longo do tempo, preservando
compatibilidade e minimizando impactos nas equipas de desenvolvimento.

## 2.7 Síntese

Uma organização clara do código constitui um dos pilares para um
desenvolvimento sustentável, colaborativo e de elevada qualidade.
