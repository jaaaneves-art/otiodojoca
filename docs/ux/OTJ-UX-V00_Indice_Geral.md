# OTJ-UX-V00 --- Índice Geral da Experiência do Utilizador

## Objetivo

A coleção **OTJ-UX** documenta a experiência do utilizador (User
Experience) da plataforma **O Tio do Joca (OTJ)**. O objetivo é garantir
uma interface consistente, acessível, intuitiva e centrada nas
necessidades dos diferentes perfis de utilizador.
