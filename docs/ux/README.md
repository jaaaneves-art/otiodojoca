# UX

## O Tio do Joca (OTJ)

Bem-vindo à coleção de **Experiência do Utilizador (UX)** da plataforma
**O Tio do Joca (OTJ)**.

Esta coleção documenta os princípios de experiência do utilizador, as
personas, as jornadas de utilização, os wireframes, o design system e as
recomendações de acessibilidade.

## Estrutura da Coleção

  Documento    Descrição
  ------------ -------------------
  OTJ-UX-V00   Índice Geral
  OTJ-UX-V01   Personas
  OTJ-UX-V02   Jornadas e Fluxos
  OTJ-UX-V03   Wireframes
  OTJ-UX-V04   Design System
  OTJ-UX-V05   Acessibilidade

## Objetivos

-   Colocar o utilizador no centro do desenvolvimento.
-   Uniformizar a experiência de utilização.
-   Definir padrões visuais e de interação.
-   Garantir acessibilidade e inclusão.
-   Apoiar as equipas de Produto, Design, Frontend e QA.

## Estado

**Estado:** Concluído (versão inicial).

A documentação deverá evoluir sempre que forem introduzidas novas
funcionalidades, padrões de interface ou melhorias na experiência de
utilização.
