# OTJ-UX-V05 --- Acessibilidade

## Objetivo

Definir as recomendações de acessibilidade da plataforma **O Tio do Joca
(OTJ)** para garantir que todos os utilizadores possam utilizar a
aplicação de forma eficaz, independentemente das suas capacidades.

## Princípios

-   Perceptível
-   Operável
-   Compreensível
-   Robusto

Seguir, sempre que possível, as recomendações das WCAG 2.2 (nível AA).

## Interface

### Cores

-   Garantir contraste suficiente entre texto e fundo.
-   Não utilizar apenas a cor para transmitir informação.

### Tipografia

-   Tamanho legível.
-   Boa legibilidade.
-   Espaçamento adequado.

### Navegação

-   Compatível com teclado.
-   Ordem lógica do foco.
-   Indicador visual de foco.

### Formulários

-   Etiquetas associadas aos campos.
-   Mensagens de erro claras.
-   Campos obrigatórios identificados.

### Imagens

-   Texto alternativo (alt).
-   Evitar imagens que contenham informação sem alternativa textual.

### Conteúdos Multimédia

-   Legendas para vídeos.
-   Transcrições quando aplicável.

## Compatibilidade

-   Desktop
-   Tablet
-   Smartphone
-   Leitores de ecrã
-   Navegação por teclado

## Testes

Recomenda-se validar regularmente:

-   Contraste
-   Navegação por teclado
-   Leitores de ecrã
-   Escalabilidade do texto
-   Responsividade

## Boas Práticas

-   Utilizar linguagem simples.
-   Evitar animações desnecessárias.
-   Não bloquear o zoom do navegador.
-   Manter consistência na interface.
