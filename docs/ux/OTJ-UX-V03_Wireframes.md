# OTJ-UX-V03 --- Wireframes

## Objetivo

Definir a estrutura visual das principais páginas da plataforma OTJ
antes da implementação da interface gráfica.

## Princípios

-   Simplicidade
-   Consistência
-   Hierarquia visual
-   Navegação intuitiva
-   Design responsivo

## Wireframes Principais

### Página Inicial

-   Cabeçalho
-   Pesquisa
-   Destaques
-   Notícias
-   Eventos
-   Rodapé

### Página de Pesquisa

-   Campo de pesquisa
-   Filtros
-   Lista de resultados
-   Paginação

### Perfil de Utilizador

-   Dados pessoais
-   Atividade
-   Definições
-   Mensagens

### Evento

-   Informações
-   Localização
-   Calendário
-   Inscrição

### Marketplace

-   Lista de anúncios
-   Detalhe do produto
-   Contacto
-   Filtros

### Painel de Administração

-   Dashboard
-   Utilizadores
-   Conteúdos
-   Estatísticas
-   Configuração

## Recomendações

-   Criar protótipos de baixa fidelidade antes do design final.
-   Validar os fluxos com utilizadores.
-   Manter componentes reutilizáveis.
