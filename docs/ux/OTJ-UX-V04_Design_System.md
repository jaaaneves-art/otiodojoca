# OTJ-UX-V04 --- Design System

## Objetivo

Definir o sistema de design da plataforma **O Tio do Joca (OTJ)** para
assegurar consistência visual, reutilização de componentes e uma
experiência de utilização uniforme.

## Princípios

-   Consistência
-   Clareza
-   Simplicidade
-   Acessibilidade
-   Responsividade

## Identidade Visual

### Cores

-   Cor primária
-   Cor secundária
-   Cores de destaque
-   Cores de estados (sucesso, aviso, erro e informação)

### Tipografia

-   Família tipográfica
-   Hierarquia de títulos
-   Texto corrido
-   Legendas

### Espaçamento

-   Grelha base
-   Margens
-   Espaçamentos entre componentes

## Componentes

### Botões

-   Primário
-   Secundário
-   Perigo
-   Apenas ícone

### Formulários

-   Campos de texto
-   Áreas de texto
-   Seletores
-   Caixas de verificação
-   Botões de opção

### Navegação

-   Barra superior
-   Menu lateral
-   Breadcrumbs
-   Paginação

### Cartões

-   Notícias
-   Eventos
-   Produtos
-   Organizações

### Tabelas

-   Listagens
-   Ordenação
-   Filtros
-   Paginação

### Mensagens

-   Sucesso
-   Informação
-   Aviso
-   Erro

## Ícones

-   Utilizar uma biblioteca consistente.
-   Manter o mesmo estilo em toda a aplicação.
-   Acompanhar os ícones com texto quando necessário.

## Responsividade

-   Desktop
-   Tablet
-   Smartphone
