# OTJ-SQL-V00 — Implementação da Base de Dados

## Objetivo

Esta fase reúne toda a implementação física da Base de Dados do projeto **O Tio do Joca (OTJ)** em PostgreSQL/Supabase.

Parte dos modelos conceptuais e dos Diagramas Entidade-Relacionamento (ERD) desenvolvidos nas fases anteriores e transforma-os numa estrutura SQL completa, segura, escalável e preparada para evolução futura.

---

# Conteúdo

Esta fase inclui toda a implementação SQL da plataforma:

- Estrutura da Base de Dados
- Schemas
- Tabelas
- Chaves Primárias (Primary Keys)
- Chaves Estrangeiras (Foreign Keys)
- Constraints
- Índices
- Views
- Funções
- Triggers
- Políticas RLS (Row Level Security)
- Roles e Permissões
- Dados iniciais (Seed Data)
- Migrações
- Estratégias de otimização

---

# Objetivos

A implementação deverá assegurar:

- Integridade dos dados
- Elevado desempenho
- Escalabilidade
- Segurança
- Facilidade de manutenção
- Compatibilidade total com PostgreSQL e Supabase
