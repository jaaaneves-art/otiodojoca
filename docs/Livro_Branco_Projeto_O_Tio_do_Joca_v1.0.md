# Livro Branco do Projeto O Tio do Joca

## Versão Oficial 1.0

**Data de aprovação:** 13 de julho de 2026

------------------------------------------------------------------------

## 1. Missão

O Tio do Joca pretende preservar, organizar e divulgar o património
cultural português, tornando-o acessível às gerações atuais e futuras
através de meios digitais e impressos.

O projeto pretende ser uma referência nacional na divulgação da
história, tradições, cultura popular, património, natureza, agricultura
e identidade portuguesa.

------------------------------------------------------------------------

## 2. Visão

Construir o maior arquivo digital independente dedicado à cultura
tradicional portuguesa, combinando rigor histórico, tecnologia moderna e
participação da comunidade.

------------------------------------------------------------------------

## 3. Valores

-   Rigor histórico
-   Independência editorial
-   Respeito pelas fontes
-   Neutralidade política
-   Neutralidade religiosa
-   Preservação do património
-   Partilha do conhecimento
-   Transparência
-   Acesso livre sempre que possível

------------------------------------------------------------------------

## 4. Objetivos

O projeto deverá reunir informação sobre:

-   História de Portugal
-   História Local
-   Património
-   Monumentos
-   Castelos
-   Igrejas
-   Museus
-   Aldeias
-   Vilas
-   Cidades
-   Tradições
-   Festas
-   Romarias
-   Gastronomia
-   Agricultura
-   Jardinagem
-   Animais
-   Calendário agrícola
-   Calendário lunar
-   Provérbios
-   Ditados
-   Lendas
-   Mitos
-   Personagens portuguesas
-   Biodiversidade
-   Caminhos
-   Turismo
-   Genealogia
-   Arquivos históricos
-   Fotografia antiga
-   Cartografia
-   Meteorologia popular

------------------------------------------------------------------------

## 5. Plataforma

O projeto será composto por vários módulos independentes.

### Portal Principal

Centro de toda a informação.

### Comunidade

Inclui:

-   Fórum
-   Perguntas e respostas
-   Comentários
-   Perfis de utilizador

### Feira

Compra e venda de:

-   Produtos agrícolas
-   Artesanato
-   Livros
-   Colecionismo
-   Ferramentas
-   Equipamentos

### Biblioteca

Arquivo documental.

### Almanaque

Publicação permanente.

### Enciclopédia

Artigos organizados por temas.

------------------------------------------------------------------------

## 6. Tecnologia

A plataforma deverá privilegiar tecnologias modernas e abertas.

Atualmente prevê-se:

-   Next.js
-   React
-   Supabase
-   PostgreSQL
-   Tailwind CSS
-   TypeScript

A arquitetura deverá permitir futuras migrações sem perda de informação.

------------------------------------------------------------------------

## 7. Princípios de Desenvolvimento

Cada funcionalidade deverá obedecer a:

-   Simplicidade
-   Robustez
-   Segurança
-   Escalabilidade
-   Facilidade de utilização
-   Compatibilidade móvel
-   Compatibilidade desktop

------------------------------------------------------------------------

## 8. Segurança

Todo o desenvolvimento deverá respeitar:

-   RGPD
-   Proteção de dados pessoais
-   Backups automáticos
-   Controlo de permissões
-   Auditoria das ações principais

------------------------------------------------------------------------

## 9. Conteúdo

Todo o conteúdo deverá ser:

-   Verificável
-   Datado
-   Referenciado sempre que possível
-   Escrito em português europeu
-   Revisto antes da publicação

------------------------------------------------------------------------

## 10. Inteligência Artificial

A IA será utilizada como ferramenta de apoio.

Nunca substitui a decisão editorial.

Poderá ser utilizada para:

-   organização
-   pesquisa
-   indexação
-   revisão
-   geração de rascunhos
-   apoio à programação

------------------------------------------------------------------------

## 11. Comunidade

A comunidade deverá incentivar:

-   colaboração
-   entreajuda
-   respeito
-   educação
-   preservação da memória

Não serão tolerados:

-   insultos
-   discurso de ódio
-   spam
-   fraude
-   desinformação deliberada

------------------------------------------------------------------------

## 12. Sustentabilidade

O projeto deverá procurar sustentabilidade financeira através de:

-   publicidade não intrusiva
-   donativos
-   parcerias
-   venda de livros
-   serviços premium opcionais

Sem comprometer a independência editorial.

------------------------------------------------------------------------

## 13. Organização

O projeto deverá manter documentação permanente.

Inclui:

-   Livro Branco
-   Livro Técnico
-   Manual Editorial
-   Manual da Comunidade
-   Histórico de alterações

------------------------------------------------------------------------

## 14. Evolução

Este documento define apenas os princípios permanentes.

As funcionalidades poderão evoluir sem alterar os valores fundamentais
do projeto.

------------------------------------------------------------------------

## 15. Compromisso

O Projeto **O Tio do Joca** assume como compromisso preservar, valorizar
e transmitir a cultura portuguesa utilizando as melhores ferramentas
tecnológicas disponíveis, mantendo sempre o respeito pela verdade
histórica, pela comunidade e pelo património nacional.

------------------------------------------------------------------------
