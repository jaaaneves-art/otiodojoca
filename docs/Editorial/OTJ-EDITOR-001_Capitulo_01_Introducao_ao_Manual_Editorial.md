# Capítulo 1 --- Introdução ao Manual Editorial

## 1.1 Finalidade

O Manual Editorial estabelece os princípios, normas e procedimentos para
a criação, revisão, publicação e manutenção dos conteúdos do Projeto O
Tio do Joca.

Constitui a referência para autores, revisores, editores e
administradores editoriais, assegurando coerência, qualidade e
credibilidade em todo o ecossistema.

## 1.2 Objetivos

O manual tem como objetivos:

-   uniformizar critérios editoriais;
-   garantir rigor e qualidade dos conteúdos;
-   promover uma linguagem clara e consistente;
-   definir o fluxo editorial;
-   assegurar a preservação do património documental.

## 1.3 Âmbito

Aplica-se a todos os conteúdos do projeto, incluindo artigos,
documentos, notícias, agenda, enciclopédia, biblioteca digital, fórum
moderado, feira, páginas institucionais e restantes publicações.

## 1.4 Relação com a Documentação

Este documento complementa os documentos OTJ-CORE, o Livro Branco, o
Livro Técnico, o Modelo de Dados, a Especificação das APIs, o Guia de
Desenvolvimento e o Manual de Operações.

## 1.5 Estrutura

Os capítulos seguintes abordarão:
