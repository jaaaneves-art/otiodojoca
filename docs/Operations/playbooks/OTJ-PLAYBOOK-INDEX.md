# Índice Geral dos Playbooks

## Objetivo

Os Playbooks definem os procedimentos de resposta a incidentes, crises e eventos operacionais relevantes da plataforma OTJ.

## Coleção

### PLAYBOOK-001 a PLAYBOOK-010
- API indisponível
- Base de dados indisponível
- Falha de autenticação
- Falha de deployment
- Ataque DDoS
- Incidente de segurança
- Perda de dados
- Certificado expirado
- Serviço degradado
- Comunicação de incidente

### PLAYBOOK-011 a PLAYBOOK-015
- Recuperação pós-incidente
- Lições aprendidas
- Escalada técnica
- Continuidade de negócio
- Encerramento do incidente
