# OTJ-PLAYBOOK-V01 — PLAYBOOK-001 a PLAYBOOK-010

# Playbooks de Resposta a Incidentes

## PLAYBOOK-001 — API Indisponível
Objetivo: Restaurar rapidamente a disponibilidade da API.
Passos:
1. Confirmar incidente.
2. Verificar logs e monitorização.
3. Identificar causa.
4. Restaurar serviço.
5. Validar funcionamento.
6. Comunicar resolução.

---

## PLAYBOOK-002 — Base de Dados Indisponível
- Confirmar estado.
- Verificar PostgreSQL/Supabase.
- Restaurar se necessário.
- Validar integridade.

---

## PLAYBOOK-003 — Falha de Autenticação
- Verificar fornecedor de identidade.
- Validar certificados e chaves.
- Testar login.

---

## PLAYBOOK-004 — Falha de Deployment
- Suspender rollout.
- Executar rollback.
- Validar serviços.

---

## PLAYBOOK-005 — Ataque DDoS
- Ativar proteção.
- Limitar tráfego.
- Monitorizar recuperação.

---

## PLAYBOOK-006 — Incidente de Segurança
- Isolar sistemas afetados.
- Preservar evidências.
- Notificar responsáveis.
- Iniciar investigação.

---

## PLAYBOOK-007 — Perda de Dados
- Interromper alterações.
- Restaurar backup.
- Validar consistência.

---

## PLAYBOOK-008 — Certificado Expirado
- Renovar certificado.
- Publicar nova versão.
- Validar HTTPS.

---

## PLAYBOOK-009 — Serviço Degradado
- Identificar gargalos.
- Escalar recursos.
- Validar desempenho.

---

## PLAYBOOK-010 — Comunicação de Incidente
- Informar equipa.
- Atualizar utilizadores.
- Registar cronologia.
