# OTJ-PROJECT-MANAGEMENT

**Projeto:** O Tio do Joca (OTJ)\
**Área:** Gestão do Projeto\
**Estado:** Documento de referência

------------------------------------------------------------------------

# 1. Objetivo

Este documento apresenta a organização da gestão do projeto OTJ,
centralizando os processos de planeamento, acompanhamento, decisões e
registo da evolução do projeto.

------------------------------------------------------------------------

# 2. Estrutura

A área de Project Management organiza-se nas seguintes secções:

-   **README.md** --- visão geral da pasta.
-   **OTJ-PROJECT-AUDIT.md** --- auditorias técnicas e organizacionais.
-   **decisions/** --- decisões arquiteturais e de gestão.
-   **risks/** --- identificação e acompanhamento de riscos.
-   **sessions/** --- histórico de todas as sessões de trabalho.

------------------------------------------------------------------------

# 3. Gestão das Sessões

Cada sessão deve conter:

-   Número sequencial da sessão;
-   Data;
-   Hora de início e fim;
-   Duração;
-   Objetivos;
-   Trabalho realizado;
-   Próximos passos;
-   **Árvore (`tree`) da estrutura relevante do projeto no final da
    sessão**, quando existirem alterações estruturais.

A inclusão do `tree` passa a fazer parte do padrão de documentação das
sessões, permitindo acompanhar a evolução da organização do repositório.

------------------------------------------------------------------------

# 4. Princípios

-   Documentação atualizada.
-   Decisões registadas.
-   Rastreabilidade.
-   Organização consistente.
-   Evolução incremental.

------------------------------------------------------------------------

# 5. Relação com as restantes áreas

A Gestão do Projeto integra e acompanha a evolução da documentação de:

-   Architecture
-   ADR
-   Backend
-   Frontend
-   API
-   Security
-   DevOps
-   QA

------------------------------------------------------------------------

# 6. Finalidade

Este documento funciona como ponto de entrada para toda a documentação
de gestão do projeto e estabelece as regras de organização e
acompanhamento da evolução do OTJ.
