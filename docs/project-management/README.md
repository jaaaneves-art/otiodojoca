## Convenções

### Sessões

Cada sessão é registada num ficheiro próprio:

SESSION-AAAAMMDDHHMM.md

O nome utiliza a data e hora de início da sessão.

### Conteúdo mínimo

- Data
- Hora de início
- Hora de fim
- Duração
- Objetivos
- Trabalho realizado
- Documentação criada
- Código desenvolvido
- Commits Git
- Decisões tomadas
- Problemas encontrados
- Soluções aplicadas
- Próxima sessão
- Checklist

## Fluxo de trabalho

1. Abrir um novo ficheiro de sessão.
2. Registar a hora de início.
3. Trabalhar normalmente.
4. No final:
   - Registar hora de fim.
   - Atualizar o resumo.
   - Fazer commit.
   - Fazer push.
