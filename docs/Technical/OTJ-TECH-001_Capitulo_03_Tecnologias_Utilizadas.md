# OTJ-TECH-001 --- Livro Técnico do Projeto O Tio do Joca

# Capítulo 3 --- Tecnologias Utilizadas

## 3.1 Finalidade

Este capítulo identifica as tecnologias adotadas pelo Projeto O Tio do
Joca e estabelece os princípios que orientam a sua seleção, utilização e
evolução.

## 3.2 Objetivos

A escolha das tecnologias deverá:

-   privilegiar soluções estáveis e maduras;
-   promover interoperabilidade;
-   reduzir dependências desnecessárias;
-   facilitar manutenção e evolução;
-   favorecer padrões abertos sempre que possível.

## 3.3 Tecnologias Base

A implementação poderá recorrer, entre outras, às seguintes tecnologias:

-   HTML5, CSS3 e JavaScript/TypeScript;
-   React e Next.js para a interface Web;
-   Supabase para autenticação, base de dados e armazenamento;
-   PostgreSQL como sistema de gestão de base de dados;
-   APIs REST e outros mecanismos de integração;
-   Git para controlo de versões.

A adoção de novas tecnologias deverá respeitar os princípios definidos
nos documentos CORE.

## 3.4 Critérios de Seleção

A avaliação de novas tecnologias deverá considerar:

-   segurança;
-   desempenho;
-   documentação;
-   suporte da comunidade;
-   sustentabilidade;
-   compatibilidade com a arquitetura existente.

## 3.5 Atualização Tecnológica

As tecnologias utilizadas deverão ser revistas periodicamente,
permitindo atualizações planeadas sem comprometer a estabilidade da
plataforma.

## 3.6 Síntese

A seleção criteriosa das tecnologias assegura uma plataforma moderna,
sustentável e preparada para responder à evolução das necessidades do
Projeto O Tio do Joca.
