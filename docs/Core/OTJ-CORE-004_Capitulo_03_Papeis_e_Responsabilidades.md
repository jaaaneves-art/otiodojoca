# OTJ-CORE-004 --- Modelo Conceptual da Comunidade

# Capítulo 3 --- Papéis e Responsabilidades

## 3.1 Finalidade

Este capítulo define os papéis conceptuais existentes na comunidade do
Projeto O Tio do Joca, bem como as responsabilidades associadas a cada
um. A distribuição clara de funções contribui para uma comunidade
organizada, transparente e colaborativa.

## 3.2 Princípios

A atribuição de papéis deverá respeitar os seguintes princípios:

-   proporcionalidade das responsabilidades;
-   transparência;
-   confiança;
-   competência;
-   prestação de contas;
-   possibilidade de evolução.

## 3.3 Papéis Conceptuais

O ecossistema poderá incluir, entre outros, os seguintes papéis:

-   Visitante;
-   Membro;
-   Colaborador;
-   Autor;
-   Editor;
-   Moderador;
-   Administrador;
-   Parceiro institucional.

Cada papel representa um conjunto de responsabilidades e permissões,
podendo uma mesma pessoa acumular diferentes funções quando devidamente
autorizada.

## 3.4 Responsabilidades Gerais

Independentemente do papel desempenhado, todos os participantes deverão:

-   respeitar os princípios do projeto;
-   proteger o património informacional;
-   agir de boa-fé;
-   cumprir as normas da comunidade;
-   colaborar para um ambiente construtivo.

## 3.5 Delegação de Funções

Determinadas responsabilidades poderão ser delegadas, de forma
temporária ou permanente, desde que exista um processo transparente e
documentado.

A delegação não elimina a responsabilidade pela supervisão das funções
atribuídas.

## 3.6 Revisão dos Papéis

Os papéis poderão ser revistos à medida que a comunidade evolua,
garantindo que continuam adequados às necessidades do projeto e às
competências dos participantes.

## 3.7 Síntese

A definição clara de papéis e responsabilidades promove uma governação
equilibrada da comunidade, facilita a colaboração e reforça a confiança
entre todos os participantes do Projeto O Tio do Joca.
