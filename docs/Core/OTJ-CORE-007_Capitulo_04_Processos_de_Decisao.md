# OTJ-CORE-007 --- Modelo de Governação do Projeto

# Capítulo 4 --- Processos de Decisão

## 4.1 Finalidade

Este capítulo define os princípios conceptuais que orientam a tomada de
decisão no Projeto O Tio do Joca. O objetivo é garantir que as decisões
são transparentes, fundamentadas, proporcionais e coerentes com a missão
e os documentos CORE.

## 4.2 Objetivos

Os processos de decisão deverão:

-   assegurar clareza e transparência;
-   identificar responsáveis pela decisão;
-   promover participação quando adequado;
-   garantir registo e rastreabilidade;
-   apoiar a melhoria contínua.

## 4.3 Princípios

As decisões deverão ser:

-   fundamentadas;
-   documentadas;
-   proporcionais;
-   consistentes;
-   orientadas para o interesse do projeto.

## 4.4 Níveis de Decisão

O modelo poderá distinguir diferentes níveis de decisão, incluindo:

-   estratégicas;
-   organizacionais;
-   editoriais;
-   técnicas;
-   operacionais.

Cada decisão deverá ser tomada pelo nível de responsabilidade adequado.

## 4.5 Registo

As decisões com impacto relevante deverão ser registadas, identificando:

-   responsável;
-   data;
-   fundamentação;
-   âmbito;
-   efeitos previstos.

## 4.6 Revisão

Sempre que necessário, as decisões poderão ser revistas à luz de nova
informação, mantendo histórico das alterações e respetivas
justificações.

## 4.7 Síntese

Um processo de decisão claro fortalece a governação do Projeto O Tio do
Joca, reforça a confiança dos participantes e contribui para a evolução
consistente do ecossistema.
