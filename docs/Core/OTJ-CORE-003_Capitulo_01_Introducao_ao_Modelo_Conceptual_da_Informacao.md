# OTJ-CORE-003 --- Modelo Conceptual da Informação

# Capítulo 1 --- Introdução ao Modelo Conceptual da Informação

## 1.1 Finalidade

O presente documento define o modelo conceptual da informação do Projeto
O Tio do Joca.

Enquanto os documentos anteriores estabelecem a identidade do projeto e
a organização dos seus módulos, este documento identifica a informação
que é produzida, armazenada, relacionada, pesquisada, preservada e
disponibilizada pelo ecossistema.

O objetivo é criar uma visão comum da informação, independente da
tecnologia utilizada para a implementar.

## 1.2 Objetivos

O Modelo Conceptual da Informação tem como objetivos:

-   definir os principais tipos de informação do ecossistema;
-   estabelecer relações entre conteúdos;
-   apoiar a arquitetura da base de dados;
-   orientar a indexação e a pesquisa;
-   facilitar a interoperabilidade entre módulos;
-   preservar a consistência dos dados ao longo do tempo.

## 1.3 Âmbito

Este documento aplica-se a toda a informação gerida pelo Projeto O Tio
do Joca, incluindo conteúdos editoriais, informação produzida pela
comunidade, documentos, metadados, recursos multimédia e elementos de
configuração.

Não descreve a implementação técnica nem o modelo físico da base de
dados, os quais serão tratados em documentação própria.

## 1.4 Princípios

A informação do ecossistema deverá respeitar os seguintes princípios:

-   unicidade;
-   integridade;
-   reutilização;
-   rastreabilidade;
-   preservação;
-   acessibilidade;
-   interoperabilidade.

## 1.5 Estrutura do Documento

Nos capítulos seguintes serão definidos:

1.  Tipos de informação;
2.  Entidades conceptuais;
3.  Relações entre entidades;
4.  Metadados;
5.  Taxonomias;
6.  Ciclo de vida da informação;
7.  Pesquisa e indexação;
8.  Preservação digital.
