# OTJ-CORE-007 --- Modelo de Governação do Projeto

# Capítulo 2 --- Estrutura Organizacional

## 2.1 Finalidade

Este capítulo define a estrutura organizacional conceptual do Projeto O
Tio do Joca. A sua finalidade é identificar os principais órgãos,
equipas e níveis de responsabilidade que asseguram a coordenação e o
desenvolvimento sustentável do projeto.

## 2.2 Objetivos

A estrutura organizacional deverá:

-   definir responsabilidades de forma clara;
-   facilitar a coordenação entre áreas;
-   apoiar a tomada de decisão;
-   promover colaboração;
-   assegurar continuidade institucional.

## 2.3 Estrutura Conceptual

A organização poderá integrar, entre outros:

-   Direção do Projeto;
-   Coordenação Editorial;
-   Coordenação Técnica;
-   Coordenação da Comunidade;
-   Administração da Plataforma;
-   Equipas de Colaboração;
-   Parceiros Institucionais.

Cada elemento possui responsabilidades próprias e atua de forma
articulada com os restantes.

## 2.4 Princípios Organizacionais

A estrutura deverá respeitar:

-   simplicidade;
-   transparência;
-   subsidiariedade;
-   cooperação;
-   prestação de contas;
-   melhoria contínua.

## 2.5 Articulação

Os diferentes órgãos e equipas deverão cooperar de forma permanente,
partilhando informação, coordenando atividades e contribuindo para os
objetivos comuns do projeto.

## 2.6 Evolução

A estrutura organizacional poderá evoluir acompanhando o crescimento do
Projeto O Tio do Joca, preservando sempre a coerência com os princípios
definidos nos documentos CORE.

## 2.7 Síntese

Uma estrutura organizacional clara constitui a base para uma governação
eficaz, permitindo que o projeto cresça de forma coordenada, sustentável
e alinhada com a sua missão.
