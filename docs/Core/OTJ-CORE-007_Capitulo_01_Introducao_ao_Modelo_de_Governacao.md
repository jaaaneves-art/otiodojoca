# OTJ-CORE-007 --- Modelo de Governação do Projeto

# Capítulo 1 --- Introdução ao Modelo de Governação do Projeto

## 1.1 Finalidade

O presente documento define o modelo conceptual de governação do Projeto
O Tio do Joca.

A governação estabelece a forma como o projeto é organizado, dirigido,
acompanhado e desenvolvido ao longo do tempo, garantindo continuidade,
transparência e coerência com a missão definida nos restantes documentos
CORE.

## 1.2 Objetivos

O modelo de governação tem como objetivos:

-   definir a estrutura de governação;
-   clarificar responsabilidades;
-   orientar a tomada de decisão;
-   assegurar a sustentabilidade do projeto;
-   promover transparência e prestação de contas.

## 1.3 Âmbito

Este documento aplica-se à organização global do Projeto O Tio do Joca,
abrangendo a gestão estratégica, editorial, técnica e comunitária, bem
como as relações entre os diferentes órgãos e equipas.

## 1.4 Princípios Fundamentais

A governação deverá assentar em:

-   transparência;
-   responsabilidade;
-   colaboração;
-   sustentabilidade;
-   independência;
-   melhoria contínua.

## 1.5 Estrutura do Documento

Nos capítulos seguintes serão abordados:

1.  Estrutura Organizacional;
2.  Papéis e Responsabilidades;
3.  Processos de Decisão;
4.  Gestão Estratégica;
5.  Gestão Operacional;
6.  Evolução Institucional;
7.  Síntese do Modelo de Governação.
