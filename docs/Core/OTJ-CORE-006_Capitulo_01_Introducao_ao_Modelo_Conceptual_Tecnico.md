# OTJ-CORE-006 --- Modelo Conceptual Técnico

# Capítulo 1 --- Introdução ao Modelo Conceptual Técnico

## 1.1 Finalidade

O presente documento estabelece o modelo conceptual técnico do Projeto O
Tio do Joca.

A sua finalidade é definir os princípios técnicos que suportam o
ecossistema, independentemente das tecnologias concretas utilizadas em
cada fase de implementação. Este documento funciona como ponte entre a
arquitetura conceptual e a arquitetura técnica detalhada.

## 1.2 Objetivos

O Modelo Conceptual Técnico tem como objetivos:

-   definir os princípios técnicos fundamentais;
-   orientar a evolução tecnológica do ecossistema;
-   promover modularidade e reutilização;
-   assegurar interoperabilidade entre módulos;
-   servir de referência para futuras implementações.

## 1.3 Âmbito

O documento aplica-se a toda a infraestrutura lógica do projeto,
incluindo aplicações, serviços, dados, integrações, segurança e
componentes partilhados.

Não descreve tecnologias específicas nem decisões de implementação, que
serão documentadas em manuais e documentação técnica próprios.

## 1.4 Princípios Fundamentais

O modelo técnico deverá respeitar os seguintes princípios:

-   modularidade;
-   interoperabilidade;
-   escalabilidade;
-   segurança;
-   desempenho;
-   acessibilidade;
-   sustentabilidade tecnológica.

## 1.5 Estrutura do Documento

Nos capítulos seguintes serão abordados:

1.  Arquitetura Técnica;
2.  Serviços Comuns;
3.  Integração entre Componentes;
4.  Segurança;
5.  Dados e Persistência;
6.  Evolução Tecnológica;
7.  Síntese do Modelo Técnico.
