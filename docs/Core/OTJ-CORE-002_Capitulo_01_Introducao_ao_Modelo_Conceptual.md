# OTJ-CORE-002 --- Modelo Conceptual dos Módulos do Ecossistema

# Capítulo 1 --- Introdução ao Modelo Conceptual

## 1.1 Finalidade

O presente documento descreve o modelo conceptual dos módulos que
constituem o ecossistema do Projeto O Tio do Joca.

Enquanto o **OTJ-CORE-001** define a identidade, missão e arquitetura
conceptual do projeto, este documento especifica os módulos que
materializam essa visão, clarificando a sua finalidade,
responsabilidades e relações.

## 1.2 Objetivos

Este documento tem como objetivos:

-   definir claramente cada módulo do ecossistema;
-   delimitar responsabilidades e fronteiras funcionais;
-   evitar sobreposição de funcionalidades;
-   servir de referência para a arquitetura técnica e para o
    desenvolvimento da plataforma;
-   apoiar a evolução consistente do projeto.

## 1.3 Âmbito

O modelo conceptual aplica-se a todos os módulos oficiais do
ecossistema, incluindo os atuais e os que venham a ser integrados
futuramente.

As especificações técnicas, modelos de dados e procedimentos de
implementação serão tratados em documentos próprios.

## 1.4 Módulos do Ecossistema

Na versão inicial, o ecossistema é composto pelos seguintes módulos:

-   Portal Institucional;
-   Fórum da Comunidade;
-   Biblioteca Digital;
-   Almanaque;
-   Enciclopédia;
-   Feira;
-   Área de Administração.

Cada módulo deverá possuir identidade funcional própria, reutilizando os
serviços comuns disponibilizados pelo núcleo da plataforma.

## 1.5 Princípios

Os módulos deverão respeitar os seguintes princípios:

-   modularidade;
-   interoperabilidade;
-   reutilização de serviços;
-   experiência de utilização consistente;
-   evolução independente sem perda de integração.

## 1.6 Relação com Outros Documentos

Este documento complementa o OTJ-CORE-001 e servirá de base ao Livro
Técnico, aos modelos de dados e às especificações funcionais de cada
módulo.
