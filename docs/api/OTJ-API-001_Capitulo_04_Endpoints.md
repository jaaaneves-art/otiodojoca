# Capítulo 4 --- Endpoints

## 4.1 Finalidade

Este capítulo define a organização conceptual dos endpoints das APIs do
Projeto O Tio do Joca, estabelecendo uma estrutura uniforme para acesso
aos diferentes recursos do ecossistema.

## 4.2 Objetivos

Os endpoints deverão:

-   organizar os serviços por domínio funcional;
-   manter nomenclatura consistente;
-   facilitar descoberta e utilização;
-   reduzir ambiguidades;
-   permitir evolução controlada.

## 4.3 Domínios Funcionais

Os endpoints poderão ser agrupados, entre outros, pelos seguintes
domínios:

-   autenticação;
-   utilizadores e perfis;
-   conteúdos;
-   categorias e etiquetas;
-   pesquisa;
-   comunidade;
-   multimédia;
-   eventos;
-   administração;
-   notificações.

## 4.4 Operações

Os recursos deverão disponibilizar operações adequadas à sua natureza,
privilegiando padrões consistentes para consulta, criação, atualização e
eliminação quando aplicável.

## 4.5 Convenções

Os endpoints deverão adotar convenções uniformes de nomenclatura,
estrutura de caminhos, parâmetros, paginação, ordenação e filtragem,
promovendo previsibilidade e reutilização.

## 4.6 Evolução

A introdução de novos endpoints deverá preservar a compatibilidade com
versões anteriores sempre que possível, recorrendo a versionamento
quando necessário.

## 4.7 Síntese

Uma organização consistente dos endpoints facilita o desenvolvimento, a
integração e a manutenção das APIs do Projeto O Tio do Joca.
