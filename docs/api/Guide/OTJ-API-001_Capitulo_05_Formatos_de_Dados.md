# Capítulo 5 --- Formatos de Dados

## 5.1 Finalidade

Este capítulo define os formatos de representação da informação
utilizados pelas APIs do Projeto O Tio do Joca, assegurando consistência
na troca de dados entre todos os componentes do ecossistema.

## 5.2 Objetivos

Os formatos de dados deverão:

-   garantir interoperabilidade;
-   facilitar validação;
-   promover legibilidade;
-   assegurar consistência entre serviços;
-   permitir evolução compatível.

## 5.3 Representação dos Dados

As APIs deverão utilizar formatos normalizados e amplamente suportados
para pedidos e respostas, privilegiando estruturas simples, consistentes
e bem documentadas.

## 5.4 Estrutura das Mensagens

As mensagens deverão incluir, quando aplicável:

-   dados solicitados;
-   metadados;
-   informação de paginação;
-   estado da operação;
-   mensagens informativas.

## 5.5 Convenções

Os formatos deverão seguir convenções uniformes para:

-   nomes dos campos;
-   tipos de dados;
-   datas e horas;
-   valores nulos;
-   listas e objetos.

## 5.6 Compatibilidade

As alterações aos formatos de dados deverão preservar a compatibilidade
sempre que possível, recorrendo a versionamento quando necessário.

## 5.7 Síntese

A uniformização dos formatos de dados facilita a integração, reduz erros
de implementação e contribui para a estabilidade das APIs do Projeto O
Tio do Joca.
