# OTJ-CODE-OF-CONDUCT

# Código de Conduta

## Objetivo

Promover um ambiente colaborativo, respeitador e profissional para todos os participantes do projeto **O Tio do Joca (OTJ)**.

## Princípios

- Respeito mútuo.
- Comunicação clara e construtiva.
- Colaboração e partilha de conhecimento.
- Inclusão e igualdade de oportunidades.
- Foco na qualidade do projeto.

## Comportamentos Esperados

- Tratar todos com cordialidade.
- Aceitar críticas técnicas de forma construtiva.
- Fundamentar decisões com argumentos técnicos.
- Cumprir os Standards de Desenvolvimento (SDR).

## Comportamentos Inaceitáveis

- Assédio ou discriminação.
- Linguagem ofensiva.
- Divulgação de informação confidencial.
- Introdução deliberada de código malicioso.
- Desrespeito pelas políticas de segurança.

## Resolução de Conflitos

1. Dialogar entre as partes.
2. Envolver os responsáveis do projeto quando necessário.
3. Registar decisões relevantes.
