# OTJ-SDR-INDEX

## Objetivo
Os Standards de Desenvolvimento (SDR) definem as regras obrigatórias para garantir consistência, qualidade, segurança e manutenção do projeto **O Tio do Joca (OTJ)**.

## SDR-001 a SDR-010
- Convenções de Código
- Git Flow
- Estratégia de Branches
- Convenções de Commits
- Pull Requests
- Code Review
- Logging
- Tratamento de Erros
- APIs REST
- Base de Dados

## SDR-011 a SDR-020
- Testes
- Segurança
- Performance
- Documentação
- Gestão de Dependências
- CI/CD
- Observabilidade
- Configuração
- Qualidade de Código
- Inteligência Artificial
