# OTJ-SDR-V02 — SDR-011 a SDR-020

# Standards de Desenvolvimento

---

## SDR-011 — Testes

**Objetivo**
Garantir que todas as funcionalidades são verificadas antes da integração.

**Normas**
- Testes unitários obrigatórios para regras de negócio.
- Testes de integração para APIs e serviços.
- Testes end-to-end para fluxos críticos.
- Correção imediata de testes falhados.

---

## SDR-012 — Segurança

**Normas**
- Princípio do menor privilégio.
- Validação de entradas.
- Proteção contra OWASP Top 10.
- Dependências atualizadas.

---

## SDR-013 — Performance

**Normas**
- Evitar consultas desnecessárias.
- Utilizar cache quando apropriado.
- Monitorizar tempos de resposta.
- Definir objetivos de desempenho.

---

## SDR-014 — Documentação

**Normas**
- Atualizar documentação em cada alteração relevante.
- README obrigatório em cada módulo.
- Exemplos de utilização quando aplicável.

---

## SDR-015 — Gestão de Dependências

**Normas**
- Utilizar versões estáveis.
- Rever vulnerabilidades regularmente.
- Remover dependências não utilizadas.

---

## SDR-016 — CI/CD

**Normas**
- Build automático.
- Execução automática de testes.
- Análise de qualidade.
- Deploy controlado por ambiente.

---

## SDR-017 — Observabilidade

**Normas**
- Métricas.
- Logs estruturados.
- Tracing distribuído.
- Alertas para serviços críticos.

---

## SDR-018 — Configuração

**Normas**
- Configuração por variáveis de ambiente.
- Nunca guardar segredos no código.
- Ambientes isolados.

---

## SDR-019 — Qualidade de Código

**Normas**
- Análise estática.
- Cobertura mínima de testes.
- Revisão obrigatória.
- Refatorização contínua.

---

## SDR-020 — Inteligência Artificial

**Normas**
- Prompts versionados.
- Respostas auditáveis.
- Supervisão humana em decisões críticas.
- Respeito pelos princípios de utilização responsável da IA.
