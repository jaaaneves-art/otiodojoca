# OTJ-DEV-001 --- Guia de Desenvolvimento

# Capítulo 3 --- Convenções de Programação

## 3.1 Finalidade

Este capítulo estabelece as convenções de programação a adotar no
Projeto O Tio do Joca, promovendo consistência, legibilidade e qualidade
em todo o código desenvolvido.

## 3.2 Objetivos

As convenções deverão:

-   facilitar a leitura do código;
-   uniformizar estilos de desenvolvimento;
-   reduzir erros;
-   simplificar manutenção;
-   favorecer colaboração entre programadores.

## 3.3 Nomenclatura

Os identificadores deverão utilizar nomes claros, descritivos e
consistentes. A nomenclatura deverá seguir as convenções definidas para
cada linguagem e tecnologia utilizada no projeto.

## 3.4 Estrutura do Código

O código deverá privilegiar:

-   funções pequenas e reutilizáveis;
-   separação de responsabilidades;
-   baixo acoplamento;
-   elevada coesão;
-   documentação adequada.

## 3.5 Comentários e Documentação

Os comentários deverão explicar decisões técnicas relevantes e não
repetir aquilo que o código já expressa. As interfaces públicas deverão
ser documentadas de forma consistente.

## 3.6 Tratamento de Erros

O tratamento de erros deverá ser uniforme, previsível e devidamente
registado quando necessário, evitando ocultar falhas ou comprometer a
segurança da aplicação.

## 3.7 Síntese

A adoção de convenções comuns contribui para um código mais limpo,
consistente, sustentável e fácil de evoluir.
