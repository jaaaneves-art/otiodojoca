# Capítulo 8 --- Síntese do Guia de Desenvolvimento

## 8.1 Finalidade

Este capítulo consolida os princípios definidos ao longo do Guia de
Desenvolvimento do Projeto O Tio do Joca, estabelecendo uma visão
integrada das práticas de desenvolvimento adotadas pelo ecossistema.

## 8.2 Visão Integrada

O desenvolvimento deverá assentar numa organização clara do código,
convenções consistentes, controlo de versões, testes, revisão técnica e
processos de integração contínua, assegurando qualidade e
sustentabilidade.

## 8.3 Princípios Permanentes

O desenvolvimento do projeto deverá respeitar permanentemente:

-   qualidade;
-   simplicidade;
-   reutilização;
-   documentação;
-   colaboração;
-   segurança;
-   melhoria contínua.

## 8.4 Alinhamento

O Guia de Desenvolvimento deverá manter alinhamento com:

-   os documentos OTJ-CORE;
-   o Livro Branco;
-   o Livro Técnico;
-   o Modelo de Dados;
-   a Especificação das APIs;
-   a restante documentação operacional.

## 8.5 Síntese Final

O Guia de Desenvolvimento constitui a referência para todos os
colaboradores técnicos do Projeto O Tio do Joca, promovendo uma cultura
de desenvolvimento consistente, colaborativa e preparada para a evolução
contínua do ecossistema.
