# OTJ-DEV-001 --- Guia de Desenvolvimento

# Capítulo 6 --- Revisão de Código

## 6.1 Finalidade

Este capítulo estabelece os princípios para a revisão de código no
Projeto O Tio do Joca, assegurando que todas as alterações relevantes
são avaliadas antes de serem integradas na base de código principal.

## 6.2 Objetivos

A revisão de código deverá:

-   melhorar a qualidade do software;
-   identificar defeitos precocemente;
-   garantir conformidade com as normas do projeto;
-   promover a partilha de conhecimento;
-   reduzir riscos de manutenção.

## 6.3 Âmbito

Sempre que aplicável, as alterações deverão ser sujeitas a revisão
técnica por outro colaborador antes da aprovação e integração.

## 6.4 Critérios de Revisão

A revisão deverá verificar, entre outros aspetos:

-   correção funcional;
-   legibilidade do código;
-   conformidade com as convenções de programação;
-   impacto na arquitetura;
-   segurança;
-   desempenho;
-   atualização da documentação.

## 6.5 Registo

As revisões deverão ficar documentadas, identificando o revisor, a
decisão tomada e as observações relevantes para futura referência.

## 6.6 Melhoria Contínua

As revisões de código deverão ser encaradas como um processo de
aprendizagem contínua, incentivando a colaboração e a evolução técnica
da equipa.

## 6.7 Síntese

Uma revisão de código consistente contribui para a robustez,
sustentabilidade e qualidade global do Projeto O Tio do Joca.
