# OTJ-DEV-001 --- Guia de Desenvolvimento

# Capítulo 4 --- Git e Controlo de Versões

## 4.1 Finalidade

Este capítulo estabelece as práticas de utilização do Git e do sistema
de controlo de versões do Projeto O Tio do Joca, garantindo um processo
de desenvolvimento colaborativo, seguro e rastreável.

## 4.2 Objetivos

A gestão de versões deverá:

-   preservar o histórico do projeto;
-   facilitar o trabalho em equipa;
-   reduzir conflitos;
-   apoiar revisões de código;
-   permitir recuperação de versões anteriores.

## 4.3 Estratégia de Branches

O repositório deverá utilizar uma estratégia clara de branches,
distinguindo desenvolvimento, integração, correções e versões estáveis.

## 4.4 Commits

Os commits deverão ser:

-   pequenos e focados;
-   descritivos;
-   frequentes;
-   relacionados com uma única alteração lógica.

## 4.5 Pull Requests e Revisão

As alterações relevantes deverão ser submetidas através de pull
requests, acompanhadas de revisão técnica antes da integração no ramo
principal.

## 4.6 Releases

As versões publicadas deverão ser identificadas por tags, acompanhadas
por notas de lançamento e documentação das alterações introduzidas.

## 4.7 Síntese

Uma utilização disciplinada do Git assegura colaboração eficiente,
rastreabilidade e elevada qualidade no desenvolvimento do Projeto O Tio
do Joca.
