# Capítulo 1 --- Introdução ao Guia de Desenvolvimento

## 1.1 Finalidade

O Guia de Desenvolvimento estabelece as normas, processos e boas
práticas para o desenvolvimento do Projeto O Tio do Joca.

Constitui a referência para todos os programadores e colaboradores
técnicos, assegurando consistência na implementação, manutenção e
evolução do ecossistema.

## 1.2 Objetivos

O guia tem como objetivos:

-   uniformizar práticas de desenvolvimento;
-   facilitar a colaboração entre equipas;
-   garantir qualidade do código;
-   reduzir riscos técnicos;
-   promover manutenção sustentável.

## 1.3 Âmbito

Aplica-se a todos os componentes do projeto, incluindo frontend,
backend, base de dados, APIs, scripts, documentação técnica e
infraestrutura.

## 1.4 Relação com a Documentação

Este documento complementa os documentos OTJ-CORE, o Livro Branco, o
Livro Técnico, o Modelo de Dados e a Especificação das APIs,
transformando os seus princípios em práticas de desenvolvimento.

## 1.5 Estrutura

Os capítulos seguintes abordarão:

1.  Organização do Código;
2.  Convenções de Programação;
3.  Git e Controlo de Versões;
4.  Testes e Qualidade;
5.  Revisão de Código;
6.  Integração e Entrega Contínuas;
7.  Síntese.
