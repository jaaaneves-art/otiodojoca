# OTJ-ADR-INDEX

# Índice Geral dos Architecture Decision Records (ADR)

## Objetivo

Este documento serve como índice mestre de todas as decisões arquiteturais do projeto **O Tio do Joca (OTJ)**.

Cada ADR documenta uma decisão importante, o seu contexto, a decisão tomada e as respetivas consequências.

# Convenções

Cada ADR segue a estrutura:

1. Contexto
2. Decisão
3. Consequências

Os ADR são imutáveis. Alterações futuras deverão originar novos ADR, preservando o histórico.
