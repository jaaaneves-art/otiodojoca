# 1. Introdução

Esta pasta contém a documentação técnica referente ao Backend da
plataforma **O Tio do Joca**.

O Backend é responsável pela lógica de negócio, processamento de dados,
segurança, integrações e comunicação com a base de dados.

------------------------------------------------------------------------

# 2. Objetivo

A documentação desta área serve para:

-   Organizar a arquitetura do Backend
-   Apoiar o desenvolvimento
-   Facilitar manutenção futura
-   Registar decisões técnicas
-   Permitir evolução controlada da plataforma
