# OTJ-QA-V11 — Checklist QA

**Código:** OTJ-QA-V11  
**Projeto:** O Tio do Joca (OTJ)  
**Área:** Qualidade e Testes (QA)  
**Versão:** 1.0  
**Estado:** Em desenvolvimento

---

# Objetivo

Disponibilizar uma checklist de Qualidade e Testes (QA) para validar que cada versão da plataforma OTJ cumpre os requisitos mínimos antes da sua disponibilização em produção.

---

# Checklist de Desenvolvimento

## Código

- [ ] Código revisto.
- [ ] Convenções de programação respeitadas.
- [ ] Documentação atualizada.
- [ ] Sem erros de compilação.

## Testes Unitários

- [ ] Todos os testes executados.
- [ ] Sem falhas críticas.
- [ ] Cobertura adequada dos componentes principais.

## Testes de Integração

- [ ] Integrações validadas.
- [ ] APIs testadas.
- [ ] Base de dados validada.

## Testes End-to-End

- [ ] Fluxos principais executados.
- [ ] Autenticação validada.
- [ ] Navegação funcional.

## Segurança

- [ ] HTTPS ativo.
- [ ] Sem vulnerabilidades críticas conhecidas.
- [ ] Gestão de acessos validada.

## Performance

- [ ] Tempos de resposta aceitáveis.
- [ ] Recursos dentro dos limites previstos.
- [ ] Sem degradação significativa.

## Aceitação

- [ ] Critérios de aceitação cumpridos.
- [ ] Bugs críticos corrigidos.
- [ ] Aprovação da equipa responsável.

---

# Revisão Final

Antes do deploy confirmar:

- [ ] Documentação concluída.
- [ ] Backups disponíveis.
- [ ] Pipeline CI/CD aprovada.
- [ ] Monitorização ativa.
- [ ] Plano de rollback preparado.

---

# Conclusão

Esta checklist deverá ser utilizada antes de cada entrega importante da plataforma OTJ, promovendo consistência, qualidade e redução de riscos.
