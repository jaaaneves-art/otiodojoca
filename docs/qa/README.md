# Objetivo

Esta pasta reúne toda a documentação relativa à estratégia de Qualidade e Testes (QA) do projeto O Tio do Joca (OTJ).

O seu objetivo é definir os processos, metodologias, critérios e procedimentos necessários para garantir a qualidade, estabilidade, desempenho e fiabilidade da plataforma ao longo de todo o ciclo de desenvolvimento.

---

# Âmbito

A documentação desta área inclui:

- Estratégia de Qualidade
- Testes Unitários
- Testes de Integração
- Testes End-to-End (E2E)
- Testes de Performance
- Testes de Segurança
- Testes de Usabilidade
- Testes de Aceitação
- Gestão de Bugs
- Métricas de Qualidade
- Checklists de Validação
