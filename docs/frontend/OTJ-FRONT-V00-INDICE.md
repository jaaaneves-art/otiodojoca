# OTJ-FRONT-V00 --- Índice Geral do Frontend

## Projeto

**O Tio do Joca (OTJ)**

## Área

Frontend da Plataforma OTJ

------------------------------------------------------------------------

# Objetivo

Este documento define o índice geral da documentação técnica do frontend
da plataforma O Tio do Joca.

O frontend representa a camada de interação com os utilizadores,
disponibilizando interfaces para cidadãos, produtores, instituições,
cooperativas, municípios e restantes participantes da plataforma.

------------------------------------------------------------------------
