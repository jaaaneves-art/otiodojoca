# OTJ Frontend

## Projeto

**O Tio do Joca (OTJ)**

Frontend da plataforma digital OTJ.

------------------------------------------------------------------------

# Objetivo

Este diretório contém o código e a documentação relacionada com a camada
frontend da plataforma.

O frontend é responsável pela interface utilizada pelos diferentes tipos
de utilizadores:

-   cidadãos;
-   produtores;
-   cooperativas;
-   associações;
-   municípios;
-   administradores.
