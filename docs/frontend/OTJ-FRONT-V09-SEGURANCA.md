# OTJ-FRONT-V09 --- Segurança do Frontend

## Projeto

**O Tio do Joca (OTJ)**

## Área

Frontend da Plataforma OTJ

------------------------------------------------------------------------

# Objetivo

Este documento define as principais regras de segurança aplicadas ao
frontend da plataforma O Tio do Joca.

A segurança deve proteger utilizadores, dados e comunicações entre
sistemas.

------------------------------------------------------------------------

# Princípios de Segurança

O frontend deve seguir:

-   proteção de dados pessoais;
-   validação de informação;
-   comunicação segura;
-   controlo de acessos.

------------------------------------------------------------------------

# Comunicação Segura

Todas as comunicações devem utilizar:

-   HTTPS;
-   APIs autenticadas;
-   ligações protegidas.

------------------------------------------------------------------------

# Autenticação e Sessões

Devem ser aplicadas boas práticas:

-   gestão segura de sessões;
-   expiração de acessos;
-   proteção de tokens;
-   controlo de permissões.

------------------------------------------------------------------------

# Validação de Dados

Todos os dados introduzidos pelo utilizador devem ser validados.

Inclui:

-   formulários;
-   uploads;
-   conteúdos publicados;
-   pesquisas.

------------------------------------------------------------------------

# Proteção da Interface

A aplicação deve prevenir:

-   exposição de dados privados;
-   acesso indevido a páginas;
-   manipulação de permissões.

------------------------------------------------------------------------

# Privacidade

A plataforma deve respeitar:

-   proteção de dados dos utilizadores;
-   minimização de informação recolhida;
-   transparência na utilização dos dados.

------------------------------------------------------------------------

# Boas Práticas de Desenvolvimento

Inclui:

-   atualização de dependências;
-   revisão de código;
-   testes de segurança;
-   controlo de versões.

------------------------------------------------------------------------

# Evolução Futura

A segurança deve acompanhar:

-   crescimento da plataforma;
-   novos serviços;
-   aplicações móveis;
-   integrações externas.

------------------------------------------------------------------------
