# OTJ-FRONT-V05 --- Interface e Experiência de Utilização

## Projeto

**O Tio do Joca (OTJ)**

## Área

Frontend da Plataforma OTJ

------------------------------------------------------------------------

# Objetivo

Este documento define os princípios de interface e experiência de
utilização (UX/UI) da plataforma O Tio do Joca.

A interface deve ser simples, clara e acessível a todos os tipos de
utilizadores.

------------------------------------------------------------------------

# Princípios de Design

## Simplicidade

A informação deve ser apresentada de forma clara, evitando complexidade
desnecessária.

------------------------------------------------------------------------

## Acessibilidade

A plataforma deve permitir utilização por diferentes públicos.

Considerações:

-   tamanhos de letra ajustáveis;
-   bom contraste visual;
-   navegação simples;
-   compatibilidade com dispositivos diferentes.

------------------------------------------------------------------------

## Consistência

Os elementos visuais devem manter o mesmo comportamento em toda a
aplicação.

Inclui:

-   cores;
-   botões;
-   menus;
-   formulários.

------------------------------------------------------------------------

# Estrutura Visual

A interface deve incluir:

-   cabeçalho principal;
-   navegação;
-   área de conteúdo;
-   ações do utilizador;
-   rodapé.

------------------------------------------------------------------------

# Responsividade

O frontend deve adaptar-se a:

-   computadores;
-   tablets;
-   smartphones.

A experiência deve manter qualidade em todos os dispositivos.

------------------------------------------------------------------------

# Identidade OTJ

A interface deve transmitir:

-   proximidade;
-   comunidade;
-   tradição;
-   agricultura;
-   cultura portuguesa;
-   confiança.

------------------------------------------------------------------------

# Componentes Visuais

Inclui:

-   cartões de informação;
-   calendários;
-   mapas;
-   listas;
-   perfis;
-   publicações.

------------------------------------------------------------------------

# Experiência do Utilizador

A plataforma deve facilitar:

-   descoberta de conteúdos;
-   participação comunitária;
-   gestão de atividades;
-   comunicação entre utilizadores.

------------------------------------------------------------------------
