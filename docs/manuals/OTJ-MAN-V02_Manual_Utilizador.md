# OTJ-MAN-V02 --- Manual do Utilizador

## Objetivo

Este manual explica como um utilizador utiliza a plataforma OTJ no dia a
dia, desde o registo até à participação nas diferentes funcionalidades
disponíveis.

## Público-alvo

-   Utilizadores registados
-   Novos membros da comunidade

## Primeiros Passos

1.  Criar uma conta.
2.  Confirmar o endereço de correio eletrónico.
3.  Iniciar sessão.
4.  Completar o perfil.

## Gestão do Perfil

-   Editar dados pessoais.
-   Alterar palavra-passe.
-   Atualizar fotografia.
-   Configurar preferências.

## Utilização da Plataforma

### Pesquisa

-   Procurar conteúdos, eventos e organizações.
-   Utilizar filtros.

### Fórum

-   Criar tópicos.
-   Responder a discussões.
-   Editar publicações próprias.

### Eventos

-   Consultar eventos.
-   Inscrever-se quando aplicável.
-   Partilhar eventos.

### Marketplace

-   Consultar anúncios.
-   Contactar produtores.
-   Publicar anúncios, caso tenha permissões.

### Mensagens

-   Enviar e receber mensagens privadas.
-   Gerir notificações.

## Boas Práticas

-   Utilizar uma palavra-passe forte.
-   Manter os dados do perfil atualizados.
-   Respeitar as regras da comunidade.
-   Não partilhar credenciais.

## Resolução de Problemas

-   Recuperação de palavra-passe.
-   Problemas de autenticação.
-   Contacto com o suporte.
