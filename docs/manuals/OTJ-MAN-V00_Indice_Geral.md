# OTJ-MAN-V00 --- Índice Geral dos Manuais

## Objetivo

A coleção **OTJ-MAN** reúne os manuais de utilização da plataforma **O
Tio do Joca (OTJ)**, adaptados aos diferentes perfis de utilizador.

Os documentos desta coleção explicam como utilizar a plataforma de forma
eficaz, segura e consistente, complementando a documentação técnica e de
produto.

## Organização

Cada manual deverá incluir:

-   Introdução
