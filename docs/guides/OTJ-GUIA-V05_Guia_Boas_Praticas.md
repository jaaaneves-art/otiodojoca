# OTJ-GUIA-V05 --- Guia de Boas Práticas

## Objetivo

Este guia reúne recomendações para garantir uma utilização segura,
eficiente e consistente da plataforma OTJ por utilizadores,
administradores e equipas técnicas.

## Destinatários

-   Utilizadores
-   Editores
-   Moderadores
-   Administradores
-   DevOps
-   Equipa técnica

## Boas Práticas Gerais

-   Manter os dados atualizados.
-   Utilizar palavras-passe fortes e autenticação multifator.
-   Respeitar as políticas da plataforma.
-   Documentar alterações relevantes.

## Segurança

-   Aplicar o princípio do menor privilégio.
-   Não partilhar credenciais.
-   Rever permissões periodicamente.
-   Atualizar software e dependências.

## Gestão de Conteúdos

-   Validar a informação antes da publicação.
-   Respeitar direitos de autor.
-   Utilizar linguagem clara e inclusiva.
-   Arquivar conteúdos desatualizados.

## Operação

-   Monitorizar o sistema regularmente.
-   Verificar backups.
-   Testar procedimentos de recuperação.
-   Registar incidentes e respetiva resolução.

## Desenvolvimento

-   Utilizar controlo de versões.
-   Rever código antes da integração.
-   Automatizar testes.
-   Atualizar a documentação em cada alteração significativa.

## Proteção de Dados

-   Minimizar a recolha de dados pessoais.
-   Cumprir o RGPD.
-   Definir políticas de retenção.
-   Registar acessos quando aplicável.

## Lista de Verificação

-   Ambiente atualizado
-   Backups validados
-   Monitorização ativa
-   Testes executados
-   Documentação atualizada
