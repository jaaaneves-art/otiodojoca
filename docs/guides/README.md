# Guides

## O Tio do Joca (OTJ)

Bem-vindo à coleção de **Guias** da plataforma **O Tio do Joca (OTJ)**.

Esta coleção reúne procedimentos práticos para instalação, configuração,
atualização, migração e adoção de boas práticas, servindo de apoio às
equipas técnicas e de administração.

## Estrutura da Coleção

  Documento      Descrição
  -------------- -----------------------
  OTJ-GUIA-V00   Índice Geral
  OTJ-GUIA-V01   Guia de Instalação
  OTJ-GUIA-V02   Guia de Configuração
  OTJ-GUIA-V03   Guia de Atualização
  OTJ-GUIA-V04   Guia de Migração
  OTJ-GUIA-V05   Guia de Boas Práticas

## Objetivos

-   Apoiar a instalação e operação da plataforma.
-   Uniformizar procedimentos técnicos.
-   Facilitar atualizações e migrações.
-   Promover boas práticas de administração e segurança.
-   Complementar a documentação técnica e funcional.
