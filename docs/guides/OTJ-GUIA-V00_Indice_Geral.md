# OTJ-GUIA-V00 --- Índice Geral dos Guias

## Objetivo

A coleção **OTJ-GUIA** reúne os guias práticos da plataforma **O Tio do
Joca (OTJ)**. Estes documentos descrevem procedimentos técnicos e
operacionais para instalação, configuração, atualização, migração e
adoção de boas práticas.

## Estrutura da Coleção

  Código         Documento               Destinatário
  -------------- ----------------------- -----------------
  OTJ-GUIA-V00   Índice Geral            Todos
  OTJ-GUIA-V01   Guia de Instalação      Administradores
  OTJ-GUIA-V02   Guia de Configuração    Administradores
  OTJ-GUIA-V03   Guia de Atualização     Equipa Técnica
  OTJ-GUIA-V04   Guia de Migração        Equipa Técnica
  OTJ-GUIA-V05   Guia de Boas Práticas   Todos

## Estrutura Recomendada

Cada guia deverá incluir:

-   Objetivo
-   Público-alvo
-   Pré-requisitos
-   Procedimentos passo a passo
-   Verificações finais
-   Resolução de problemas
-   Referências
