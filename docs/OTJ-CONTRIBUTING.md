# OTJ-CONTRIBUTING

# Guia de Contribuição

## Objetivo

Este documento define as regras para qualquer contribuição ao projeto **O Tio do Joca (OTJ)**.

## Antes de começar

1. Ler o README.
2. Consultar o OTJ-ROADMAP.
3. Verificar o OTJ-BACKLOG.
4. Confirmar se existe ADR, SDR ou RFC aplicável.

## Fluxo de trabalho

1. Criar uma branch `feature/*`, `fix/*` ou `docs/*`.
2. Implementar a alteração.
3. Atualizar a documentação relevante.
4. Executar os testes.
5. Submeter Pull Request.
6. Obter aprovação antes da integração.

## Regras

- Não desenvolver diretamente na branch `main`.
- Todo o código deve ser revisto.
- Novas funcionalidades devem incluir testes.
- Alterações arquiteturais exigem ADR ou RFC quando aplicável.
- O CHANGELOG deve ser atualizado nas alterações relevantes.

## Checklist

- [ ] Código compilado
- [ ] Testes executados
- [ ] Documentação atualizada
- [ ] Changelog atualizado
- [ ] Pull Request criado
