# Objetivo

Esta pasta reúne toda a documentação da infraestrutura da plataforma OTJ.

O objetivo é definir a arquitetura física e lógica da infraestrutura, os componentes que suportam a plataforma e as boas práticas para garantir disponibilidade, desempenho, segurança, escalabilidade e continuidade do serviço.

---

# Âmbito

Esta documentação inclui:

- Arquitetura da infraestrutura
- Servidores
- Redes
- DNS e Domínios
- SSL/TLS
- Reverse Proxy
- Armazenamento
- Balanceamento de carga
- Cloud e VPS
- Monitorização
- Capacidade
- Checklist operacional
