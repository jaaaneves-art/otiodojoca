# OTJ-INFRA-V02 — Servidores

**Código:** OTJ-INFRA-V02  
**Projeto:** O Tio do Joca (OTJ)  
**Área:** Infrastructure  
**Versão:** 1.0  
**Estado:** Em desenvolvimento

---

# Objetivo

Definir a estratégia de utilização e gestão dos servidores que suportam a plataforma O Tio do Joca (OTJ), assegurando disponibilidade, desempenho, segurança e facilidade de manutenção.

---

# Tipos de Servidores

A infraestrutura poderá incluir:

- Servidor Web
- Servidor da API
- Servidor de Base de Dados
- Servidor de Monitorização
- Servidor de Backups
- Servidor de Desenvolvimento (quando aplicável)

---

# Sistema Operativo

Recomenda-se a utilização de uma distribuição Linux LTS para os ambientes de produção, privilegiando estabilidade, suporte prolongado e atualizações de segurança.

---

# Requisitos Gerais

Todos os servidores deverão:

- Estar atualizados.
- Possuir acesso restrito.
- Utilizar autenticação segura.
- Ser monitorizados continuamente.
- Integrar a política de backups.

---

# Gestão

Cada servidor deverá possuir documentação com:

- Função.
- Endereço de rede.
- Recursos atribuídos.
- Serviços instalados.
- Procedimentos de manutenção.

---

# Segurança

Aplicar as seguintes medidas:

- Firewall ativa.
- Acesso remoto seguro (SSH com chaves).
- Atualizações automáticas de segurança, quando adequado.
- Princípio do menor privilégio.
- Registo de eventos relevantes.

---

# Capacidade

A capacidade dos servidores deverá ser revista periodicamente com base em:

- Utilização de CPU.
- Memória RAM.
- Espaço em disco.
- Largura de banda.
- Crescimento da plataforma.

---

# Boas Práticas

- Evitar serviços desnecessários.
- Automatizar configurações.
- Testar recuperações.
- Documentar alterações.
- Planear atualizações.

---

# Conclusão

Uma gestão adequada dos servidores garante uma infraestrutura estável, segura e preparada para acompanhar a evolução do projeto OTJ.
