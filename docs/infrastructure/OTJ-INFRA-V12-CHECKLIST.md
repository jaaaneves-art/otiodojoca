# OTJ-INFRA-V12 — Checklist Operacional

**Código:** OTJ-INFRA-V12  
**Projeto:** O Tio do Joca (OTJ)  
**Área:** Infrastructure  
**Versão:** 1.0  
**Estado:** Em desenvolvimento

---

# Objetivo

Disponibilizar uma checklist operacional para validar a infraestrutura da plataforma OTJ antes da entrada em produção e durante a sua operação contínua.

---

# Checklist de Infraestrutura

## Servidores

- [ ] Servidores atualizados.
- [ ] Recursos suficientes.
- [ ] Firewall ativa.
- [ ] Acesso administrativo seguro.

## Rede

- [ ] Conectividade validada.
- [ ] Regras de firewall revistas.
- [ ] DNS funcional.
- [ ] Latência dentro dos limites.

## Segurança

- [ ] HTTPS ativo.
- [ ] Certificados válidos.
- [ ] Chaves e credenciais protegidas.
- [ ] Acessos revistos.

## Armazenamento

- [ ] Espaço disponível suficiente.
- [ ] Backups realizados.
- [ ] Testes de recuperação efetuados.
- [ ] Política de retenção aplicada.

## Monitorização

- [ ] Alertas configurados.
- [ ] Logs ativos.
- [ ] Métricas recolhidas.
- [ ] Dashboards operacionais.

## Disponibilidade

- [ ] Serviços críticos operacionais.
- [ ] Reverse Proxy funcional.
- [ ] Balanceamento validado (quando aplicável).
- [ ] Plano de recuperação disponível.

---

# Revisão Periódica

Esta checklist deverá ser revista antes de cada deploy importante e periodicamente durante a operação da plataforma.

---

# Conclusão

A utilização sistemática desta checklist contribui para uma infraestrutura estável, segura e preparada para suportar a evolução do projeto O Tio do Joca.
