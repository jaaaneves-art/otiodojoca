## Diagnóstico

Foi identificada a causa raiz do aviso:

`React does not recognize the 'asChild' prop on a DOM element.`

O componente `components/ui/button.tsx` não suportava `asChild` e propagava essa propriedade para o elemento HTML `<button>`.

## Correção

- Implementado suporte a `asChild`.
- Integração com `@radix-ui/react-slot`.
- Aviso eliminado.
- Consola React limpa.
