# OTJ-ARCH-V09 --- Segurança e Administração

**Coleção:** OTJ-ARCH --- Arquitetura do Projeto O Tio do Joca\
**Volume:** V09\
**Estado:** Aprovado\
**Versão:** 1.0

# 1. Objetivo

Definir o modelo de segurança, autenticação, autorização e administração
do ecossistema OTJ.

# 2. Princípios

-   Segurança por defeito.
-   Menor privilégio possível.
-   Auditoria permanente.
-   Gestão centralizada de permissões.
-   Conformidade com o RGPD.

# 3. Identidade

Cada utilizador possui:

-   conta;
-   perfil;
-   funções;
-   permissões.

A autenticação é única para toda a plataforma.

# 4. Perfis e Permissões

As permissões são atribuídas através de funções.

Exemplos:

-   Administrador
-   Moderador
-   Editor
-   Autor
-   Utilizador

# 5. Auditoria

Devem ser registadas:

-   criações;
-   alterações;
-   publicações;
-   eliminações lógicas;
-   acessos administrativos;
-   alterações de permissões.

# 6. Administração

Inclui:

-   gestão de utilizadores;
-   gestão de perfis;
-   gestão de funções;
-   configuração;
-   monitorização;
-   moderação.

# 7. Benefícios

-   Segurança consistente.
-   Rastreabilidade.
-   Administração simplificada.
-   Escalabilidade.

# 8. Conclusão

O modelo de Segurança e Administração garante uma gestão centralizada da
identidade, permissões e auditoria, assegurando a proteção da plataforma
e a rastreabilidade das operações.
