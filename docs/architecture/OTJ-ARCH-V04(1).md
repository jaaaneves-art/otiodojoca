# OTJ-ARCH-V04 --- Taxonomias

**Coleção:** OTJ-ARCH --- Arquitetura do Projeto O Tio do Joca\
**Volume:** V04\
**Estado:** Aprovado\
**Versão:** 1.0

# 1. Objetivo

Definir o sistema global de taxonomias do OTJ para classificar de forma
consistente entidades, conteúdos e recursos.

# 2. Princípios

-   Estrutura única para toda a plataforma.
-   Reutilização obrigatória.
-   Hierarquias ilimitadas.
-   Evolução sem alterar a arquitetura.

# 3. Conceitos

## Taxonomia

Conjunto organizado de termos de classificação.

## Termo

Elemento individual de uma taxonomia.

## Hierarquia

Os termos podem ser organizados em árvores através de relações
pai/filho.

# 4. Regras

-   Uma entidade pode possuir vários termos.
-   Um termo pode classificar várias entidades.
-   As taxonomias são independentes dos módulos.
-   Não deverão existir taxonomias duplicadas.

# 5. Exemplos

-   Categorias
-   Temas
-   Espécies
-   Culturas
-   Gastronomia
-   Património
-   Regiões
-   Atividades

# 6. Benefícios

-   Pesquisa inteligente.
-   Navegação consistente.
-   Elevada reutilização.
-   Redução de redundâncias.
-   Facilidade de evolução.

# 7. Conclusão

O sistema global de taxonomias constitui um dos pilares do modelo de
conhecimento do OTJ e deverá ser utilizado por todos os módulos da
plataforma.
