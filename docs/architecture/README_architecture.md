# Arquitetura

Esta pasta reúne toda a documentação de arquitetura do projeto **O Tio
do Joca (OTJ)**.

## Estrutura

``` text
architecture/
├── arch/
└── adr/
```

## Conteúdo

### `arch/`

Documentação arquitetural da plataforma.

Inclui:

-   Filosofia
-   Modelo do domínio
-   Entidades
-   Taxonomias
-   Arquitetura lógica
-   Arquitetura física
-   Integrações
-   Roadmap

### `adr/`

Architecture Decision Records (ADR).

Documenta todas as decisões técnicas importantes tomadas durante o
desenvolvimento da plataforma.

## Convenções

-   Toda a documentação é escrita em Markdown.
-   Os ADR seguem numeração sequencial.
-   Alterações arquiteturais relevantes devem originar um novo ADR.
