# OTJ-ARCH-V08 --- Recursos Partilhados

**Coleção:** OTJ-ARCH --- Arquitetura do Projeto O Tio do Joca\
**Volume:** V08\
**Estado:** Em elaboração\
**Versão:** 1.0

# 1. Objetivo

Definir os recursos reutilizáveis por todos os módulos da plataforma
OTJ.

# 2. Princípios

Os recursos partilhados deverão:

-   existir apenas uma vez;
-   ser reutilizados por todos os módulos;
-   possuir gestão centralizada;
-   manter consistência em toda a plataforma.

# 3. Recursos Partilhados

## Ficheiros

Imagens, documentos, áudio, vídeo e anexos.

## Contactos

Telefones, emails, websites e outros meios de contacto.

## Fontes

Referências bibliográficas, documentos oficiais e outras origens de
informação.

## Ligações Externas

Referências para páginas e serviços externos.

## Notificações

Mensagens automáticas geradas pela plataforma para informar os
utilizadores.

## Etiquetas Técnicas

Metainformação utilizada internamente para organização e pesquisa.

# 4. Integração

Todos os recursos podem ser associados a:

-   Entidades;
-   Conteúdos;
-   Organizações;
-   Eventos;
-   Utilizadores.

# 5. Benefícios

-   Redução da duplicação;
-   Reutilização transversal;
-   Gestão centralizada;
-   Facilidade de manutenção;
-   Escalabilidade.

# 6. Conclusão

Os recursos partilhados constituem uma camada comum da arquitetura OTJ,
permitindo que todos os módulos utilizem os mesmos objetos reutilizáveis
sem criar estruturas redundantes.
