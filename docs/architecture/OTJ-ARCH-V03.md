# OTJ-ARCH-V03 --- Entidades e Relações

**Coleção:** OTJ-ARCH --- Arquitetura do Projeto O Tio do Joca\
**Volume:** V03\
**Estado:** Em elaboração\
**Versão:** 1.0

# 1. Objetivo

Definir o modelo de entidades e relações que constitui o núcleo do
conhecimento do OTJ.

# 2. Entidade

Uma entidade representa qualquer elemento permanente sobre o qual o OTJ
armazena conhecimento.

Exemplos:

-   Pessoa
-   Organização
-   Planta
-   Animal
-   Produto
-   Monumento
-   Evento
-   Receita
-   Documento
-   Tradição

Cada entidade possui uma identidade única e pode ser relacionada com
qualquer outra entidade.

# 3. Tipos de Entidade

Os diferentes tipos de entidade são definidos por classificação, nunca
por tabelas independentes sempre que isso não seja necessário.

# 4. Relações

As relações representam ligações explícitas entre entidades.

Exemplos:

-   pertence a
-   localizado em
-   produzido por
-   autor de
-   relacionado com
-   participa em
-   organizado por

# 5. Princípios

-   Uma entidade pode relacionar-se com várias entidades.
-   Uma relação possui significado próprio.
-   As relações são reutilizáveis.
-   O conhecimento é construído através da rede de relações.

# 6. Benefícios

-   Elimina duplicação.
-   Facilita pesquisa inteligente.
-   Permite novas funcionalidades sem alterar o núcleo.
-   Favorece a integração entre módulos.

# 7. Conclusão

O modelo Entidades e Relações constitui a base estrutural do
conhecimento do OTJ e deverá ser reutilizado por todos os módulos da
plataforma.
