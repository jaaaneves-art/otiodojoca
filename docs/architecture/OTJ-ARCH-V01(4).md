**Coleção:** OTJ-ARCH --- Arquitetura do Projeto O Tio do Joca\
**Volume:** V01\
**Estado:** Aprovado\
**Versão:** 1.0

# 1. Objetivo

Definir a filosofia, os princípios orientadores e a arquitetura de
referência do Projeto O Tio do Joca (OTJ).

Este documento constitui a referência principal para todas as decisões
de arquitetura do projeto.

# 2. Âmbito

Aplica-se a todo o ecossistema OTJ, incluindo os módulos atuais e
futuros, serviços, APIs, aplicações móveis e PWA.

# 3. Missão

Preservar, organizar, produzir e divulgar conhecimento sobre Portugal
através de uma plataforma digital integrada, colaborativa e sustentável.

# 4. Visão

Construir uma plataforma de referência dedicada ao património português,
preparada para evoluir durante muitos anos sem perder coerência técnica.

# 5. Princípios Fundamentais

-   Preservação do património
-   Rigor da informação
-   Simplicidade
-   Reutilização
-   Modularidade
-   Escalabilidade
-   Segurança
-   Acessibilidade
-   Transparência
-   Sustentabilidade

# 6. Princípio Arquitetónico Fundamental

> Cada facto existe apenas uma vez; tudo o resto são diferentes formas
> de o relacionar, apresentar e reutilizar.

# 7. Arquitetura

A plataforma organiza-se nas seguintes camadas:

1.  Identidade
2.  Conhecimento
3.  Classificação
4.  Território
5.  Recursos Partilhados
6.  Conteúdos
7.  Interação
8.  Administração

Cada camada possui responsabilidades próprias e reutiliza serviços
comuns sempre que possível.

# 8. Decisões Arquitetónicas

-   Uma única origem para cada informação.
-   Reutilização máxima entre módulos.
-   Separação entre conhecimento e funcionalidades.
-   Arquitetura orientada ao domínio.
-   Evolução modular sem comprometer o núcleo.

# 9. Critérios de Qualidade

Toda a plataforma deverá ser:

-   consistente;
-   documentada;
-   segura;
-   testável;
-   modular;
-   preparada para evolução contínua.

# 10. Conclusão

Este volume estabelece a filosofia permanente do OTJ e deverá ser
consultado antes de qualquer decisão técnica ou funcional.
