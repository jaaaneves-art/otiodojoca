# OTJ-ARCH-V04 --- Taxonomias

**Coleção:** OTJ-ARCH --- Arquitetura do Projeto O Tio do Joca\
**Volume:** V04\
**Estado:** Em elaboração\
**Versão:** 1.0

# 1. Objetivo

Definir o sistema global de taxonomias do OTJ, permitindo classificar de
forma consistente entidades, conteúdos e recursos.

# 2. Princípios

-   Uma única estrutura de classificação para toda a plataforma.
-   Reutilização entre todos os módulos.
-   Hierarquias ilimitadas.
-   Evolução sem alterar o modelo base.

# 3. Conceitos

## Taxonomia

Conjunto organizado de termos utilizado para classificar informação.

## Termo

Elemento individual pertencente a uma taxonomia.

## Hierarquia

Os termos podem possuir relações pai/filho.

# 4. Exemplos de Taxonomias

-   Categorias
-   Temas
-   Espécies
-   Culturas
-   Património
-   Gastronomia
-   Regiões
-   Atividades

# 5. Utilização

As taxonomias poderão ser associadas a:

-   Entidades
-   Conteúdos
-   Eventos
-   Documentos
-   Organizações

# 6. Benefícios

-   Pesquisa inteligente.
-   Navegação consistente.
-   Reutilização da classificação.
-   Eliminação de categorias duplicadas.

# 7. Conclusão

O sistema global de taxonomias constitui um dos pilares da arquitetura
do OTJ e deverá ser reutilizado por todos os módulos.
