# OTJ-ARCH-V06 --- Conteúdos

**Coleção:** OTJ-ARCH --- Arquitetura do Projeto O Tio do Joca\
**Volume:** V06\
**Estado:** Aprovado\
**Versão:** 1.0

# 1. Objetivo

Definir o modelo comum para todos os conteúdos produzidos e geridos pelo
ecossistema OTJ.

# 2. Conceito de Conteúdo

Um conteúdo representa informação estruturada criada por um utilizador
ou organização sobre uma ou mais entidades.

Exemplos: - Artigo - Documento - Notícia - Evento - Receita - Página
institucional

# 3. Princípios

-   Modelo editorial comum.
-   Separação entre conteúdo e entidade.
-   Reutilização entre módulos.
-   Suporte para múltiplos idiomas.
-   Histórico de alterações.
-   Consistência editorial.

# 4. Ciclo de Vida

Todos os conteúdos seguem o mesmo fluxo:

1.  Rascunho
2.  Em revisão
3.  Aprovado
4.  Publicado
5.  Arquivado

# 5. Metadados

Cada conteúdo deverá possuir:

-   título;
-   resumo;
-   autor;
-   idioma;
-   estado;
-   palavras-chave;
-   data de criação;
-   data de atualização;
-   data de publicação.

# 6. Relações

Um conteúdo pode relacionar-se com:

-   entidades;
-   organizações;
-   localizações;
-   taxonomias;
-   ficheiros;
-   outros conteúdos.

# 7. Benefícios

-   Consistência editorial.
-   Pesquisa global.
-   Reutilização da informação.
-   Evolução modular.
-   Facilidade de manutenção.

# 8. Conclusão

O modelo de conteúdos estabelece uma estrutura editorial comum para toda
a plataforma, garantindo coerência entre todos os módulos e permitindo a
evolução futura sem perda de consistência.
