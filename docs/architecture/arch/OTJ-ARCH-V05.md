# OTJ-ARCH-V05 --- Localizações e Organizações

**Coleção:** OTJ-ARCH --- Arquitetura do Projeto O Tio do Joca\
**Volume:** V05\
**Estado:** Em elaboração\
**Versão:** 1.0

# 1. Objetivo

Definir o modelo arquitetónico para representar o território e as
organizações do ecossistema OTJ.

# 2. Localizações

O modelo de localizações deverá ser único e reutilizado por todos os
módulos.

Uma localização poderá representar:

-   País
-   Região
-   Distrito
-   Concelho
-   Freguesia
-   Lugar
-   Outro ponto geográfico relevante

Cada localização possui identidade própria e pode integrar uma
hierarquia territorial.

# 3. Organizações

As organizações representam entidades institucionais ou coletivas.

Exemplos:

-   Municípios
-   Juntas de Freguesia
-   Associações
-   Cooperativas
-   Museus
-   Empresas
-   Casas do Povo
-   Ranchos Folclóricos

As organizações são tratadas como uma especialização do conceito de
Entidade.

# 4. Relações

As organizações podem:

-   administrar conteúdos;
-   organizar eventos;
-   gerir utilizadores;
-   publicar informação;
-   relacionar-se com outras organizações.

As localizações podem ser associadas a entidades, organizações,
conteúdos e eventos.

# 5. Princípios

-   Um único modelo territorial.
-   Uma única representação para organizações.
-   Reutilização em todos os módulos.
-   Evolução sem alterar a arquitetura base.

# 6. Benefícios

-   Consistência territorial.
-   Eliminação de redundâncias.
-   Integração entre módulos.
-   Facilidade de expansão.

# 7. Conclusão

O modelo de Localizações e Organizações estabelece a base territorial e
institucional do OTJ e deverá ser reutilizado por toda a plataforma.
