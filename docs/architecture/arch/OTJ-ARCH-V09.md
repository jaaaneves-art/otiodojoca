# OTJ-ARCH-V09 --- Segurança e Administração

**Coleção:** OTJ-ARCH --- Arquitetura do Projeto O Tio do Joca\
**Volume:** V09\
**Estado:** Em elaboração\
**Versão:** 1.0

# 1. Objetivo

Definir o modelo de segurança, autenticação, autorização e administração
do ecossistema OTJ.

# 2. Princípios

-   Segurança por defeito.
-   Menor privilégio possível.
-   Auditoria de ações relevantes.
-   Gestão centralizada de permissões.
-   Conformidade com o RGPD.

# 3. Identidade e Acesso

A plataforma utiliza um sistema único de autenticação.

Cada utilizador possui:

-   conta;
-   perfil;
-   funções;
-   permissões.

# 4. Perfis e Permissões

As permissões são atribuídas através de funções, nunca diretamente ao
utilizador.

Exemplos:

-   Administrador
-   Moderador
-   Editor
-   Autor
-   Utilizador

# 5. Auditoria

Devem ser registadas ações como:

-   criação;
-   edição;
-   publicação;
-   eliminação lógica;
-   alterações de permissões;
-   acessos administrativos.

# 6. Administração

Inclui:

-   gestão de utilizadores;
-   gestão de funções;
-   configuração da plataforma;
-   monitorização;
-   moderação.

# 7. Benefícios

-   Segurança consistente.
-   Facilidade de administração.
-   Rastreabilidade.
-   Escalabilidade.
