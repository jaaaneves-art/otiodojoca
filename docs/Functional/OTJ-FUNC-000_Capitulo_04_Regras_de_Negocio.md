# OTJ-FUNC-000 --- Norma para Especificações Funcionais

# Capítulo 4 --- Regras de Negócio

## 4.1 Finalidade

Este capítulo define a forma como as Regras de Negócio deverão ser
identificadas, documentadas e mantidas nas Especificações Funcionais do
Projeto O Tio do Joca.

## 4.2 Objetivos

As Regras de Negócio deverão:

-   representar os requisitos funcionais do domínio;
-   garantir coerência entre módulos;
-   apoiar o desenvolvimento e os testes;
-   permitir rastreabilidade.

## 4.3 Identificação

Cada regra deverá possuir um identificador único, por exemplo:

-   RN-001
-   RN-002
-   RN-003

A numeração deverá ser única dentro de cada documento funcional.

## 4.4 Estrutura

Cada Regra de Negócio deverá incluir:

-   identificador;
-   título;
-   descrição;
-   justificação;
-   prioridade;
-   módulo aplicável;
-   casos de utilização relacionados.

## 4.5 Classificação

As regras poderão ser classificadas como:

-   validação;
-   processamento;
-   autorização;
-   cálculo;
-   integração;
-   operação.

## 4.6 Rastreabilidade

Cada regra deverá poder ser relacionada com Casos de Utilização,
requisitos, testes e componentes implementados.

## 4.7 Revisão

As Regras de Negócio deverão ser revistas sempre que existam alterações
funcionais relevantes.

## 4.8 Síntese

Uma gestão estruturada das Regras de Negócio assegura consistência
funcional e facilita a evolução do Projeto O Tio do Joca.
