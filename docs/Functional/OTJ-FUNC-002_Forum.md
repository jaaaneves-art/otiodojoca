# OTJ-FUNC-002 --- Fórum

## 1. Objetivo

O Fórum é o espaço de discussão da comunidade do Projeto O Tio do Joca,
permitindo a partilha de conhecimento, a colocação de dúvidas e a troca
de experiências entre os utilizadores.

## 2. Funcionalidades

-   Categorias e subcategorias
-   Criação de tópicos
-   Respostas e comentários
-   Pesquisa
-   Etiquetas (tags)
-   Anexos
-   Denúncia de conteúdos
-   Moderação
-   Tópicos fixos e encerrados
-   Histórico de edições

## 3. Perfis de Utilizador

-   Visitante (leitura pública, quando permitido)
-   Utilizador Registado
-   Moderador
-   Administrador

## 4. Fluxos Principais

-   Criar tópico
-   Responder a um tópico
-   Editar publicação
-   Pesquisar conteúdos
-   Denunciar publicação
-   Moderar conteúdos

## 5. Regras de Negócio

-   Apenas utilizadores autenticados podem criar tópicos.
-   Os moderadores podem editar, mover, bloquear ou eliminar conteúdos.
-   Todas as ações de moderação ficam registadas.
-   Os tópicos pertencem sempre a uma categoria.

## 6. Dados Utilizados

-   Categorias
-   Tópicos
-   Publicações
-   Utilizadores
-   Etiquetas
-   Anexos
-   Denúncias

## 7. Integrações

-   Autenticação
-   Perfis de Utilizador
-   Pesquisa Global
-   Sistema de Notificações
-   Administração

## 8. Critérios de Aceitação

-   Criação e resposta a tópicos.
-   Pesquisa funcional.
-   Moderação operacional.
-   Controlo de permissões.
-   Histórico de alterações.
-   Compatibilidade com dispositivos móveis.
