# OTJ-FUNC-010 --- Utilizadores

## 1. Objetivo

O módulo Utilizadores gere o registo, autenticação, perfis, preferências
e participação dos membros da comunidade do Projeto O Tio do Joca.

## 2. Funcionalidades

-   Registo de conta
-   Início e encerramento de sessão
-   Recuperação de palavra-passe
-   Gestão do perfil
-   Fotografia e informações pessoais
-   Preferências de notificações
-   Alteração de palavra-passe
-   Histórico de atividade
-   Eliminação da conta

## 3. Perfis de Utilizador

-   Visitante
-   Utilizador Registado
-   Editor
-   Moderador
-   Administrador

## 4. Fluxos Principais

-   Criar conta
-   Confirmar endereço de email
-   Iniciar sessão
-   Atualizar perfil
-   Alterar palavra-passe
-   Eliminar conta

## 5. Regras de Negócio

-   Cada utilizador possui um identificador único.
-   O endereço de email deve ser validado.
-   As palavras-passe são armazenadas de forma segura.
-   O utilizador controla as suas preferências e dados pessoais.
-   As ações relevantes ficam registadas para auditoria.

## 6. Dados Utilizados

-   Utilizadores
-   Perfis
-   Sessões
-   Preferências
-   Notificações
-   Registos de auditoria

## 7. Integrações

-   Autenticação
-   Fórum
-   Mercado da Terra
-   Biblioteca Digital
-   Administração
-   Sistema de Notificações

## 8. Critérios de Aceitação

-   Registo funcional.
-   Login e logout operacionais.
-   Recuperação de palavra-passe.
-   Gestão de perfil.
-   Compatibilidade com dispositivos móveis.
-   Conformidade com RGPD.
