# OTJ-FUNC-000 --- Norma para Especificações Funcionais

# Capítulo 3 --- Casos de Utilização (Use Cases)

## 3.1 Finalidade

Este capítulo define a forma como os Casos de Utilização deverão ser
documentados nas Especificações Funcionais do Projeto O Tio do Joca,
assegurando uma descrição uniforme dos comportamentos esperados de cada
funcionalidade.

## 3.2 Objetivos

Os Casos de Utilização deverão:

-   descrever a interação entre utilizadores e sistema;
-   identificar os atores envolvidos;
-   documentar os fluxos de execução;
-   facilitar a implementação e os testes.

## 3.3 Estrutura

Cada Caso de Utilização deverá incluir:

-   identificador único;
-   nome;
-   objetivo;
-   atores;
-   pré-condições;
-   fluxo principal;
-   fluxos alternativos;
-   pós-condições;
-   exceções.

## 3.4 Identificação

Os casos deverão utilizar um identificador normalizado, por exemplo:

-   UC-001
-   UC-002
-   UC-003

A numeração deverá ser única dentro de cada documento funcional.

## 3.5 Fluxos

Sempre que aplicável, deverão ser documentados:

-   fluxo principal;
-   fluxos alternativos;
-   fluxos de erro;
-   validações;
-   mensagens apresentadas ao utilizador.

## 3.6 Relação com Regras de Negócio

Cada Caso de Utilização deverá referenciar as regras de negócio
aplicáveis e os requisitos associados, garantindo rastreabilidade.

## 3.7 Síntese

Os Casos de Utilização constituem a principal descrição funcional do
comportamento esperado do sistema e servirão de base ao desenvolvimento
e aos testes.
