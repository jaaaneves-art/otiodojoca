# O Tio do Joca (OTJ)

Plataforma digital colaborativa dedicada à agricultura, tradições, comunidades e conhecimento popular português.

## Estado do Projeto

**Fase atual:** Sprint 0 — Preparação do desenvolvimento.

## Tecnologias

- Next.js
- React
- TypeScript
- Supabase
- PostgreSQL
- Tailwind CSS

## Estrutura

- `app/` — Aplicação Next.js
- `components/` — Componentes reutilizáveis
- `docs/` — Documentação
- `lib/` — Bibliotecas
- `public/` — Recursos públicos
- `scripts/` — Scripts de apoio
- `src/` — Código-fonte
- `supabase/` — Configuração e migrações
- `tests/` — Testes
- `types/` — Tipos TypeScript
