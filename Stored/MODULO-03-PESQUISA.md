# MODULO-03-PESQUISA

## Objetivo

Disponibilizar um sistema de pesquisa único, rápido, intuitivo e escalável para todos os anúncios do Mercado da Terra.

---

# Objetivos

- Encontrar anúncios rapidamente.
- Suportar todos os tipos de anúncio.
- Permitir filtros combinados.
- Escalar sem alterações estruturais.

---

# Pesquisa Livre

A pesquisa deverá permitir procurar por:

- Título
- Descrição
- Categoria
- Localidade
- Nome do utilizador

---

# Filtros

- Tipo de anúncio
- Categoria
- Subcategoria
- Estado
- Localização
- Distância
- Preço (quando aplicável)
- Disponibilidade
- Data de publicação

---

# Ordenação

Permitir ordenar por:

- Mais recentes
- Mais antigos
- Mais próximos
- Preço crescente
- Preço decrescente
- Relevância

---

# Resultados

Cada resultado deverá apresentar:

- Fotografia principal
- Tipo de anúncio
- Título
- Categoria
- Localização
- Preço (quando aplicável)
- Data
- Estado

---

# Funcionalidades Futuras

- Pesquisa por mapa
- Pesquisa por raio
- Pesquisa por voz
- Alertas automáticos
- Pesquisa guardada
- Recomendações personalizadas

---

# Princípios

- Um único motor de pesquisa.
- Reutilização para todos os tipos de anúncio.
- Elevado desempenho.
- Fácil evolução.
