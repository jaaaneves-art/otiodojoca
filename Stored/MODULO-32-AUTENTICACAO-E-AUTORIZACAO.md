# MODULO-32-AUTENTICACAO-E-AUTORIZACAO

## Objetivo

Definir o sistema de identidade, autenticação e autorização do OTJ, garantindo que cada utilizador acede apenas aos recursos para os quais tem permissão.

---

# Objetivos

- Autenticação segura.
- Controlo de acesso baseado em funções.
- Gestão centralizada de identidades.
- Suporte para utilizadores individuais e institucionais.

---

# Áreas

- Registo de utilizadores
- Início de sessão
- Recuperação de palavra-passe
- Gestão de sessões
- Funções (Roles)
- Permissões
- MFA
- SSO (evolução)

---

# Funcionalidades

- Login
- Logout
- Alteração de palavra-passe
- Verificação de e-mail
- Gestão de permissões
- Sessões ativas

---

# Integração

- Segurança
- Gestão de Utilizadores
- Instituições
- API e Integrações
- Configuração do Sistema

---

# Evolução

- WebAuthn / Passkeys
- OAuth2 / OpenID Connect
- Login com entidades externas
- Gestão avançada de políticas de acesso
