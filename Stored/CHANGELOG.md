# [1.0.0] - Arquitetura Inicial

## Adicionado

- Estrutura documental do Mercado da Terra.
- Arquitetura baseada numa entidade única: Anúncio.
- Suporte para múltiplos tipos de anúncio:
  - Venda
  - Compra
  - Troca
  - Oferta
  - Serviço
  - Pedido de Serviço
  - Aluguer
  - Empréstimo
  - Parceria
  - Partilha

- Definição do modelo de dados.
- Regras de negócio.
- Estrutura modular.
- Planeamento evolutivo (Roadmap).

## Objetivos

- Arquitetura modular.
- Compatibilidade retroativa.
- Escalabilidade.
- Elevada reutilização de código.
- Evolução contínua sem regressões.
