# CONVENCOES-DE-NOMENCLATURA

## Objetivo

Definir as convenções oficiais de nomenclatura utilizadas em todo o projeto OTJ, assegurando consistência, legibilidade e facilidade de manutenção.

---

## Princípios

- Nomes claros e descritivos.
- Consistência em todo o projeto.
- Evitar abreviaturas desnecessárias.
- Utilizar inglês para identificadores técnicos quando aplicável e português na documentação funcional.

---

## Convenções

### Ficheiros
- Markdown: LETRAS-MAIUSCULAS-COM-HIFENS.md
- Scripts PowerShell: Verbo-Substantivo.ps1
- Código-fonte: conforme a linguagem utilizada.

### APIs
- Endpoints em kebab-case.
- Versionamento por `/v1`, `/v2`, etc.

### Base de Dados
- Tabelas no plural.
- Chaves primárias: `id`.
- Chaves externas: `<entidade>_id`.

### Código
- Funções com verbos.
- Classes com substantivos.
- Constantes em MAIÚSCULAS.
- Variáveis com nomes significativos.
