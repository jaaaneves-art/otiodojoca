# MODULO-23-METEOROLOGIA

## Objetivo

Disponibilizar informação meteorológica para apoiar a tomada de decisão nas atividades agrícolas, pecuárias, florestais e aquícolas.

---

# Objetivos

- Apoiar o planeamento diário.
- Reduzir riscos associados às condições meteorológicas.
- Melhorar a produtividade.
- Integrar previsões com os restantes módulos do OTJ.

---

# Informação

- Temperatura
- Precipitação
- Humidade
- Vento
- Radiação solar
- Pressão atmosférica
- Índice UV
- Geada

- Alertas meteorológicos
